# 高中数学全课程

本册面向所有自学普通高中数学的学生，完整覆盖必修和选择性必修课程。主线包括函数、几何与代数、概率与统计、数学建模活动与数学探究活动；数学文化贯穿其中。

函数是高中数学的主线之一，但不是全部。本册保留图像和动态演示，同时系统补齐集合与逻辑、向量与复数、立体几何、解析几何、计数原理、概率统计、数列和导数等内容。

## 第 1 章：函数

### 1.1 函数的直觉

函数就是一个规则：

```text
输入 x
经过规则 f
输出 y
```

写成：

```text
y = f(x)
```

你可以先把函数想象成一台机器：左边输入，机器按规则处理，右边输出。

![函数机器示意图]({{ '/textbook/assets/functions/function-machine.png' | relative_url }})

例子：

```text
f(x) = 2x + 1
f(3) = 7
```

Python：

```python
def f(x):
    return 2 * x + 1

print(f(3))
```

### 1.2 函数与现实模型

现实中的许多对应关系都可以看作函数：

```text
输出 = 规则(输入)
```

例如：

```text
时间 -> 气温记录 -> 对应时刻的气温
```

计费规则也是函数：

```text
用电量 -> 阶梯电价规则 -> 应付电费
```

所以你学函数，不是为了背符号，而是为了理解“规则如何把输入变成输出”。

### 1.3 自变量和因变量

在：

```text
y = f(x)
```

里面：

- `x` 是自变量，也就是输入。
- `y` 是因变量，也就是输出。
- `f` 是规则。

### 1.4 定义域和值域

定义域：允许输入的范围。

值域：可能输出的范围。

例如：

```text
f(x) = √x
```

在实数范围内，`x` 不能小于 0。

原因是：

```text
负数没有实数范围内的算术平方根。
```

## 第 2 章：一次函数

### 2.1 形式

一次函数：

```text
y = kx + b
```

- `k` 是斜率。
- `b` 是截距。

`k` 决定倾斜程度，`b` 决定整体上下移动。

下面这个动态图展示的是：`b = 1` 不变，`k` 从负数变到正数时，直线如何旋转。

![一次函数斜率变化动态图]({{ '/textbook/assets/functions/linear-slope.gif' | relative_url }})

### 2.2 斜率

斜率表示 `x` 增加 1 时，`y` 改变多少。

```text
y = 2x + 1
```

`x` 每增加 1，`y` 增加 2。

如果：

```text
y = -3x + 1
```

`x` 每增加 1，`y` 减少 3。

### 2.3 截距

截距 `b` 表示当 `x = 0` 时，直线和 y 轴相交的位置。

例如：

```text
y = 2x + 1
```

当 `x = 0`：

```text
y = 1
```

所以截距是 1。

### 2.4 线性模型

许多线性模型都写成：

```text
y = wx + b
```

这和一次函数完全同形。

不同学科可能使用不同字母：

- 数学里常写 `k`。
- 物理、经济或计算模型里也常写 `w`，表示权重或变化率。

### 2.5 Python 画图

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)
y = 2 * x + 1

plt.plot(x, y)
plt.grid(True)
plt.show()
```

### 2.6 练习

1. `y = 3x + 2`，当 `x = 4`，`y` 是多少？
2. `y = -x + 5` 的斜率是多少？
3. `y = 2x - 3` 的截距是多少？
4. 如果一条直线斜率为正，它大致向哪个方向倾斜？

答案：

```text
1. 14
2. -1
3. -3
4. 从左下到右上。
```

## 第 3 章：二次函数

### 3.1 形式

二次函数：

```text
y = ax^2 + bx + c
```

其中 `a ≠ 0`。如果 `a = 0`，这一项就不是二次项，函数会退化成一次函数。

最简单的例子：

```text
y = x^2
```

图像是一条抛物线。

### 3.2 开口方向

`a` 决定抛物线开口方向。

```text
a > 0：开口向上，有最小值。
a < 0：开口向下，有最大值。
```

下面这个动态图只改变 `a`，你可以观察抛物线怎样从向下开口变成向上开口。

![二次函数开口变化动态图]({{ '/textbook/assets/functions/quadratic-opening.gif' | relative_url }})

### 3.3 顶点

二次函数有最大值或最小值。

例如：

```text
y = x^2
```

最小值是 0，在 `x = 0` 处取得。

这个点叫顶点。

### 3.4 平方误差与距离

均方误差：

```text
MSE = 平均((预测值 - 真实值)^2)
```

它用平方放大大误差。

Python：

```python
import numpy as np

y_true = np.array([3, 5, 7])
y_pred = np.array([2, 5, 10])
mse = np.mean((y_pred - y_true) ** 2)
print(mse)
```

## 第 4 章：反比例函数、绝对值函数和分段函数

这一章补三个常见但容易被传统教材讲散的函数。它们后面会反复出现在算法、优化和图像处理中。

### 4.1 反比例函数

反比例函数常见形式：

```text
y = k / x
```

其中 `x ≠ 0`。

例如：

```text
y = 1 / x
```

当 `x` 越接近 0，函数值变化越剧烈。

这个函数能帮助你理解：

- 除法里的“不能除以 0”。
- 对数导数 `1/x`。
- 物理和工程里的反比关系。

### 4.2 绝对值函数

绝对值表示一个数到 0 的距离。

```text
|3| = 3
|-3| = 3
```

绝对值函数：

```text
y = |x|
```

它的图像像一个 V。

在误差度量中，平均绝对误差 MAE 会用到绝对值：

```text
MAE = 平均(|预测值 - 真实值|)
```

### 4.3 分段函数

分段函数是“不同范围用不同规则”的函数。

例如：

```text
f(x) = 0, x <= 0
f(x) = x, x > 0
```

这就是 ReLU 激活函数：

```text
ReLU(x) = max(0, x)
```

神经网络里非常常见。

阈值函数也是分段函数：

```text
像素值 <= 阈值 -> 0
像素值 > 阈值 -> 255
```

### 4.4 Python

```python
def relu(x):
    return max(0, x)

for x in [-2, -1, 0, 1, 2]:
    print(x, relu(x))
```

## 第 5 章：指数函数

### 5.1 形式

```text
y = a^x
```

在初等实函数中，一般要求：

```text
a > 0 且 a ≠ 1
```

如果 `a = 1`，那么 `1^x` 永远等于 1，不再体现指数变化。

例如：

```text
y = 2^x
```

当 `x` 增大时，`y` 增长很快。

### 5.2 常见底数 e

连续增长、衰减和后续微积分中经常出现 `e`：

```text
e ≈ 2.71828
```

指数函数：

```text
e^x
```

在复利、放射性衰变、概率分布和微分方程中经常出现。

### 5.3 Python

```python
import math

print(math.exp(1))
print(math.exp(2))
```

## 第 6 章：对数函数

### 6.1 对数是什么

对数回答的问题是：

```text
底数要多少次方，才能得到这个数？
```

例如：

```text
log2(8) = 3
```

因为：

```text
2^3 = 8
```

对数函数里，底数也有要求：

```text
底数 a > 0 且 a ≠ 1
真数 x > 0
```

所以 `log2(8)` 有意义，但 `log2(-8)` 在实数范围内没有意义。

### 6.2 对数和指数互逆

```text
log_a(a^x) = x
```

这里默认 `a > 0` 且 `a ≠ 1`。

指数函数和对数函数互为反函数。图像上，它们关于 `y = x` 对称。

![指数函数和对数函数互逆]({{ '/textbook/assets/functions/exp-log-inverse.png' | relative_url }})

### 6.3 对数的应用

对数用于处理跨越多个数量级的数据，也用于信息量和交叉熵。

直觉：

- 真实类别的预测概率越高，损失越小。
- 真实类别的预测概率越低，损失越大。

例子：

```python
import math

p_good = 0.9
p_bad = 0.1
print(-math.log(p_good))
print(-math.log(p_bad))
```

## 第 7 章：三角函数

### 7.1 角度和弧度

编程里常用弧度：

```text
180° = π
90° = π/2
360° = 2π
```

### 7.2 sin、cos、tan

在直角三角形中：

```text
sin = 对边 / 斜边
cos = 邻边 / 斜边
tan = 对边 / 邻边
```

注意：`tan` 要求邻边不为 0。换成角度语言，`90°`、`270°` 这类位置的 `tan` 在实数里没有定义。

另一个更适合图像处理和信号处理的理解方式是单位圆：

```text
cosθ 是点的横坐标。
sinθ 是点的纵坐标。
```

![单位圆三角函数动态图]({{ '/textbook/assets/functions/unit-circle-trig.gif' | relative_url }})

### 7.3 图像处理中为什么用三角函数

图像旋转：

```text
x' = x cosθ - y sinθ
y' = x sinθ + y cosθ
```

这个公式默认使用数学坐标系：`x` 向右，`y` 向上，正角度是逆时针。图像处理中常见坐标是左上角为原点，`y` 向下，所以实际写 OpenCV 代码时要注意方向约定。

傅里叶变换也建立在正弦和余弦上。

Python：

```python
import math

theta = math.pi / 2
print(math.sin(theta))
print(math.cos(theta))
```

## 第 11 章：集合与常用逻辑用语

### 11.1 集合及其表示

集合是确定对象的全体，对象叫元素。常用表示法有列举法、描述法和 Venn 图。

```text
A = {1,2,3}
B = {x | x 是小于 5 的正整数}
```

`x ∈ A` 表示 `x` 属于 `A`，`C ⊆ A` 表示 `C` 是 `A` 的子集。空集记为 `∅`，它是任何集合的子集。

交集、并集、补集分别表示“同时属于”“至少属于一个”“在全集中但不属于该集合”：

```text
A ∩ B
A ∪ B
∁_U A
```

### 11.2 充分条件、必要条件与充要条件

若命题 `p -> q` 成立，则 `p` 是 `q` 的充分条件，`q` 是 `p` 的必要条件。若 `p -> q` 和 `q -> p` 都成立，则二者互为充要条件，记作 `p <-> q`。

例：“`x=2`”是“`x^2=4`”的充分条件，但不是必要条件，因为 `x=-2` 也满足结论。

### 11.3 全称量词与存在量词

```text
∀x∈A, p(x)：对 A 中所有 x，p(x) 成立
∃x∈A, p(x)：A 中至少存在一个 x，使 p(x) 成立
```

否定全称命题要改成存在命题并否定结论；否定存在命题要改成全称命题并否定结论。

```text
“所有实数的平方都大于 0”的否定：
“存在一个实数，它的平方不大于 0。”
```

反例 `x=0` 同时说明原命题为假。

## 第 12 章：相等、不等与二次关系

### 12.1 等式与不等式性质

不等式两边同时加同一个数，方向不变；同乘正数，方向不变；同乘负数，方向改变。比较大小常用作差法：研究 `a-b` 的符号。

### 12.2 基本不等式

当 `a,b >= 0` 时：

```text
√(ab) <= (a+b)/2
```

等号当且仅当 `a=b`。使用基本不等式求最值前必须检查“一正、二定、三相等”：变量为正，和或积固定，等号条件可取得。

例：正数 `x,y` 满足 `x+y=10`，则 `xy <= 25`，当 `x=y=5` 时取等号。

### 12.3 一元二次不等式

解 `ax^2+bx+c > 0` 时，把二次函数图像、方程根和不等式符号统一起来。

例：

```text
x^2 - 5x + 6 > 0
(x-2)(x-3) > 0
x < 2 或 x > 3
```

若二次项系数为正，图像开口向上，在两个实根外侧为正、内侧为负。没有实根时要结合开口方向判断恒正或恒负。

## 第 13 章：函数概念与性质深化

前十章已介绍常见函数，本章建立高中统一研究方法。

### 13.1 单调性、奇偶性、最值与周期性

- 单调性描述函数在区间上随自变量增大而增大或减小。
- 偶函数满足 `f(-x)=f(x)`，图像关于 `y` 轴对称。
- 奇函数满足 `f(-x)=-f(x)`，图像关于原点对称。
- 周期函数存在非零常数 `T`，使 `f(x+T)=f(x)`。

判断性质前必须先看定义域是否关于原点对称，证明单调性要比较任意 `x1<x2` 时函数值的大小，不能只看几个点。

### 13.2 幂函数、指数函数与对数函数

幂函数 `y=x^α` 的定义域和性质随指数变化。指数函数 `y=a^x` 与对数函数 `y=log_a x` 互为反函数：当 `a>1` 时都递增，当 `0<a<1` 时都递减。

运算规则：

```text
log_a(MN) = log_a M + log_a N
log_a(M/N) = log_a M - log_a N
log_a(M^r) = r log_a M
log_a b = ln b / ln a
```

所有对数运算都要求真数为正。

### 13.3 函数零点与模型

若连续函数在区间端点函数值异号，则区间内至少有一个零点。二分法不断缩小异号区间，可以求方程近似解。

模型选择示例：固定增量适合一次函数，固定增长率适合指数函数，先增长后下降且有极值的关系可能适合二次函数。模型只是对现实的简化，结论必须限定在合理定义域内。

## 第 14 章：三角函数与解三角形

### 14.1 任意角、弧度制与单位圆

以 `x` 轴正半轴为始边，逆时针为正角，顺时针为负角。弧度定义为弧长与半径之比：

```text
180° = π rad
弧长 l = αr
扇形面积 S = αr^2/2
```

单位圆上终边与圆交于 `(x,y)`，则 `cos α=x, sin α=y`，当 `x!=0` 时 `tan α=y/x`。

### 14.2 诱导公式与基本恒等式

```text
sin^2 α + cos^2 α = 1
tan α = sin α / cos α
sin(-α) = -sin α
cos(-α) = cos α
sin(α+2π) = sin α
cos(α+2π) = cos α
```

应通过单位圆理解符号和周期，不要把诱导公式当作互不相关的口诀。

### 14.3 和差角与倍角

```text
sin(α+β) = sinα cosβ + cosα sinβ
cos(α+β) = cosα cosβ - sinα sinβ
sin 2α = 2sinα cosα
cos 2α = cos^2α - sin^2α
```

化简时先观察角之间的关系，再决定展开还是合并。

### 14.4 正弦定理与余弦定理

在三角形 `ABC` 中，边 `a,b,c` 分别对应角 `A,B,C`：

```text
a/sin A = b/sin B = c/sin C = 2R
a^2 = b^2 + c^2 - 2bc cos A
S = 1/2 * bc * sin A
```

正弦定理适合已知两角一边或两边及其中一边的对角；余弦定理适合已知两边及夹角或三边。SSA 情形可能有两解、一解或无解，必须结合三角形条件判断。

## 第 15 章：平面向量与复数

### 15.1 平面向量

向量同时具有大小和方向。相等向量长度相等且方向相同，零向量方向不确定。向量加法满足平行四边形法则，数乘改变长度并可能改变方向。

平面向量基本定理：若 `e1,e2` 不共线，则任意平面向量 `a` 都能唯一表示为：

```text
a = λe1 + μe2
```

### 15.2 坐标运算与数量积

设 `a=(x1,y1), b=(x2,y2)`：

```text
a+b = (x1+x2, y1+y2)
a·b = x1x2 + y1y2 = |a||b|cosθ
```

`a·b=0` 且两向量非零时，两向量垂直。向量数量积可计算夹角、长度和投影，也可处理功等物理量。

### 15.3 复数

规定 `i^2=-1`，复数写成 `z=a+bi`。`a` 是实部，`b` 是虚部。复数相等要求实部、虚部分别相等。

```text
(a+bi)+(c+di) = (a+c)+(b+d)i
(a+bi)(c+di) = (ac-bd)+(ad+bc)i
```

共轭复数为 `a-bi`，模为 `|z|=√(a^2+b^2)`。复数可与复平面上的点或向量对应，使代数与几何相连。

## 第 16 章：立体几何初步

### 16.1 空间几何体、直观图与体积

认识柱、锥、台、球及其组合体，会画简单空间图形的直观图并识读三视图。

```text
柱体体积 V = Sh
锥体体积 V = Sh/3
台体体积 V = h(S1 + √(S1S2) + S2)/3
球体积 V = 4πR^3/3
球表面积 S = 4πR^2
```

### 16.2 点、直线、平面的位置关系

空间中需要区分相交、平行和异面直线。判定与性质不能混用：

- 若平面外一条直线与平面内一条直线平行，则该直线与平面平行。
- 若一条直线垂直于平面内两条相交直线，则该直线垂直于这个平面。
- 两平面平行时，其中一个平面内的直线与另一平面平行。

证明空间位置关系时，要把图形直觉转化为定理条件，图上“看起来垂直”不能作为依据。

### 16.3 空间角与距离

异面直线所成角通过平移成相交直线求得；直线与平面所成角是直线与其在平面上投影的夹角；二面角可用垂直于棱的平面截出平面角。距离问题常通过垂线、勾股定理、等体积法或后续空间向量解决。

## 第 17 章：必修概率与统计

### 17.1 随机抽样

简单随机抽样要求总体中每个个体被抽到的机会相等。分层抽样先按重要特征分层，再按各层比例抽取，适合总体内部差异明显的情形。抽样方法决定样本能否代表总体。

### 17.2 样本数据的数字特征

用平均数、中位数、众数描述中心，用极差、方差、标准差描述波动，用百分位数描述数据在排序中的相对位置。统计图包括频率分布直方图、箱线图等。

### 17.3 有限样本空间与概率

样本空间是随机试验所有可能结果组成的集合。古典概型要求有限个结果且每个结果等可能：

```text
P(A) = A 包含的样本点数 / 样本空间的样本点数
```

若 `A,B` 互斥，则 `P(A∪B)=P(A)+P(B)`；一般地：

```text
P(A∪B)=P(A)+P(B)-P(A∩B)
P(∁A)=1-P(A)
```

事件独立表示一个事件是否发生不影响另一个事件的概率，此时 `P(A∩B)=P(A)P(B)`。独立与互斥不是一回事。

## 第 18 章：数列与数学归纳法

### 18.1 数列是离散函数

数列按确定顺序排列，每一项有唯一序号，可用通项公式、递推公式、列表或图像表示。由递推式确定数列时还必须给出足够的初始条件。

### 18.2 等差数列

```text
an = a1 + (n-1)d
Sn = n(a1+an)/2 = na1 + n(n-1)d/2
```

等差数列的点 `(n,an)` 落在一条直线上，体现它与一次函数的联系。

### 18.3 等比数列

```text
an = a1 q^(n-1)
当 q != 1：Sn = a1(1-q^n)/(1-q)
当 q = 1：Sn = na1
```

等比数列与指数函数相连，可描述复利、人口变化和衰减等离散过程。使用模型时要说明公比和时间间隔。

### 18.4 数学归纳法

证明与正整数 `n` 有关的命题：

1. 验证起始值成立。
2. 假设 `n=k` 时成立。
3. 在该假设下证明 `n=k+1` 时成立。

两步缺一不可。归纳假设不是结论本身，而是连接相邻情形的桥梁。

## 第 19 章：导数及其应用

### 19.1 从平均变化率到瞬时变化率

函数在区间上的平均变化率：

```text
[f(x0+Δx)-f(x0)] / Δx
```

当 `Δx` 趋近 0，若比值趋近确定值，就得到 `f` 在 `x0` 处的导数。导数表示瞬时变化率，几何上是切线斜率。

### 19.2 基本求导规则

```text
(c)' = 0
(x^n)' = nx^(n-1)
(e^x)' = e^x
(ln x)' = 1/x
(sin x)' = cos x
(cos x)' = -sin x
(u±v)' = u'±v'
(uv)' = u'v+uv'
(u/v)' = (u'v-uv')/v^2
```

简单复合函数 `f(ax+b)` 还要乘内部函数导数 `a`。

### 19.3 用导数研究函数

在区间上 `f'(x)>0` 时函数递增，`f'(x)<0` 时函数递减。极值点通常在导数为 0 或导数不存在处寻找，并通过导数左右符号变化判断。

例：`f(x)=x^3-3x`，`f'(x)=3x^2-3=3(x-1)(x+1)`。根据符号表可得：

```text
(-∞,-1) 递增
(-1,1) 递减
(1,+∞) 递增
```

所以 `x=-1` 为极大值点，`x=1` 为极小值点。

### 19.4 优化问题

优化建模要明确自变量、目标函数、定义域，再求驻点和边界值。不能只求 `f'(x)=0` 就宣布最值，还要检查端点、不可导点和现实约束。

## 第 20 章：空间向量与立体几何

### 20.1 空间向量与坐标

建立空间直角坐标系后，向量写成 `(x,y,z)`。空间向量线性运算、数量积与平面向量类似：

```text
a·b = x1x2+y1y2+z1z2
|a| = √(x^2+y^2+z^2)
```

三个不共面的向量可作为一组基底表示空间向量。

### 20.2 方向向量与法向量

直线用方向向量描述方向，平面用法向量描述垂直方向。

- 两直线平行：方向向量共线。
- 两直线垂直：方向向量数量积为 0。
- 直线与平面平行：直线方向向量与平面法向量垂直。
- 两平面平行：法向量共线。

角度可由数量积求得。点到平面距离可转化为点间向量在法向量方向上的投影长度。

## 第 21 章：平面解析几何

### 21.1 直线与圆

直线方程常用点斜式、两点式和一般式 `Ax+By+C=0`。两直线平行或垂直可由斜率判断，竖直线需要单独处理。

```text
两点距离 = √((x2-x1)^2+(y2-y1)^2)
点 (x0,y0) 到直线 Ax+By+C=0 的距离
= |Ax0+By0+C|/√(A^2+B^2)
```

圆的标准方程：

```text
(x-a)^2+(y-b)^2=r^2
```

判断直线与圆、圆与圆的位置关系，可比较几何距离与半径，也可联立方程研究解的个数。

### 21.2 椭圆、双曲线与抛物线

- 椭圆：到两个定点的距离之和为常数。
- 双曲线：到两个定点的距离之差的绝对值为常数。
- 抛物线：到定点与定直线距离相等。

标准方程示例：

```text
椭圆：x^2/a^2 + y^2/b^2 = 1  （a>b>0）
双曲线：x^2/a^2 - y^2/b^2 = 1
抛物线：y^2 = 2px  （p>0）
```

椭圆、双曲线满足 `c^2=a^2-b^2`、`c^2=a^2+b^2`。研究圆锥曲线要同时使用定义、方程、图像和几何性质。

### 21.3 直线与圆锥曲线综合

联立直线和曲线方程通常得到一元二次方程。判别式判断交点个数，根与系数关系处理弦长、中点和斜率问题。代数运算后必须检查几何条件和特殊斜率。

## 第 22 章：计数原理、排列组合与二项式定理

### 22.1 两个计数原理

分类完成任务，各类互不重叠且覆盖全部，使用分类加法计数原理；分步完成任务，每一步都必须完成，使用分步乘法计数原理。先判断“分类”还是“分步”，再列式。

### 22.2 排列与组合

```text
排列数 A(n,m) = n!/(n-m)!
组合数 C(n,m) = n!/[m!(n-m)!]
```

排列关注顺序，组合不关注顺序。有限制条件时可用直接法、间接法、捆绑法、插空法或分类讨论，但各类必须不重不漏。

### 22.3 二项式定理

```text
(a+b)^n = Σ C(n,k) a^(n-k)b^k，k=0,...,n
```

通项 `C(n,k)a^(n-k)b^k` 可用于求指定项、常数项和系数。二项式系数满足对称性 `C(n,k)=C(n,n-k)`。

## 第 23 章：条件概率、随机变量与统计推断

### 23.1 条件概率与全概率

在 `P(B)>0` 时：

```text
P(A|B)=P(A∩B)/P(B)
P(A∩B)=P(B)P(A|B)
```

若 `B1,...,Bn` 两两互斥并覆盖样本空间，则：

```text
P(A)=Σ P(Bi)P(A|Bi)
```

条件概率改变了样本空间。独立时 `P(A|B)=P(A)`，说明知道 `B` 不改变 `A` 的概率。

### 23.2 离散型随机变量

随机变量把随机结果映射成数。分布列列出所有可能值及概率，概率之和为 1。

```text
E(X)=Σ xi*pi
Var(X)=Σ (xi-E(X))^2*pi
```

期望表示长期平均水平，方差描述波动。`n` 次独立伯努利试验中成功次数 `X` 服从二项分布 `B(n,p)`，其期望为 `np`，方差为 `np(1-p)`。不放回抽样的成功次数常用超几何分布。

### 23.3 正态分布

正态分布由均值 `μ` 和标准差 `σ` 决定，曲线关于 `x=μ` 对称。`μ` 决定中心，`σ` 决定分散程度。标准化：

```text
Z=(X-μ)/σ
```

正态模型适合许多由大量小随机影响叠加产生的测量量，但使用前应检查数据形态和背景。

### 23.4 成对数据、回归与独立性检验

散点图用于观察两个变量关系，相关系数 `r` 描述线性相关方向和强度，`-1<=r<=1`。相关不等于因果。

一元线性回归用最小二乘法拟合 `ŷ=bx+a`，残差是实际值与预测值之差。模型评价要看散点、残差和适用范围，不能只看相关系数。

`2×2` 列联表可研究两个分类变量是否独立，依据卡方统计量进行独立性检验。统计结论是带有风险水平的判断，不是逻辑上的绝对证明。

## 第 24 章：数学建模与数学探究

### 24.1 建模循环

```text
发现问题 -> 提出假设 -> 定义变量 -> 建立模型
-> 求解 -> 检验 -> 解释 -> 修正模型
```

模型报告必须写明变量和单位、数据来源、假设、推导或计算、结果、误差、适用范围。模型越复杂不一定越好，能够解释问题并接受检验才是关键。

### 24.2 必修建模项目

任选一个：

1. 用函数拟合一段公开的气温或客流时间序列，比较线性、二次或指数模型。
2. 设计校园排队时间调查，建立等待时间与服务窗口数的经验模型。
3. 测量一个不规则物体或场地，用分割、近似、坐标或抽样估计面积或体积。

### 24.3 选择性必修探究项目

任选一个：

1. 探究数列递推关系的长期行为，并尝试证明观察到的规律。
2. 用导数研究一个带现实约束的最优化问题，并比较解析结果与数值试验。
3. 收集成对数据，完成散点图、相关分析、线性回归和模型局限说明。
