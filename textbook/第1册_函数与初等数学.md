# 第 1 册：函数与初等数学

如果说第 0 册解决的是“怎么算”，这一册解决的是“一个量如何影响另一个量”。

函数是现代数学、编程、AI、图像处理的共同语言。本册会尽量用图片和动态图帮助你建立直觉。

## 第 1 章：函数

### 1.1 函数的直觉

函数就是一个规则：

```text
输入 x
经过规则 f
输出 y
```

写成：

```text
y = f(x)
```

你可以先把函数想象成一台机器：左边输入，机器按规则处理，右边输出。

![函数机器示意图]({{ '/textbook/assets/functions/function-machine.png' | relative_url }})

例子：

```text
f(x) = 2x + 1
f(3) = 7
```

Python：

```python
def f(x):
    return 2 * x + 1

print(f(3))
```

### 1.2 函数和 AI

机器学习模型本质也是函数：

```text
输出 = 模型(输入)
```

例如：

```text
图片 -> 图像分类模型 -> 猫/狗
```

图像处理算法也是函数：

```text
原图 -> 滤波函数 -> 去噪图
```

所以你学函数，不是为了背符号，而是为了理解“规则如何把输入变成输出”。

### 1.3 自变量和因变量

在：

```text
y = f(x)
```

里面：

- `x` 是自变量，也就是输入。
- `y` 是因变量，也就是输出。
- `f` 是规则。

### 1.4 定义域和值域

定义域：允许输入的范围。

值域：可能输出的范围。

例如：

```text
f(x) = √x
```

在实数范围内，`x` 不能小于 0。

原因是：

```text
负数没有实数范围内的算术平方根。
```

## 第 2 章：一次函数

### 2.1 形式

一次函数：

```text
y = kx + b
```

- `k` 是斜率。
- `b` 是截距。

`k` 决定倾斜程度，`b` 决定整体上下移动。

下面这个动态图展示的是：`b = 1` 不变，`k` 从负数变到正数时，直线如何旋转。

![一次函数斜率变化动态图]({{ '/textbook/assets/functions/linear-slope.gif' | relative_url }})

### 2.2 斜率

斜率表示 `x` 增加 1 时，`y` 改变多少。

```text
y = 2x + 1
```

`x` 每增加 1，`y` 增加 2。

如果：

```text
y = -3x + 1
```

`x` 每增加 1，`y` 减少 3。

### 2.3 截距

截距 `b` 表示当 `x = 0` 时，直线和 y 轴相交的位置。

例如：

```text
y = 2x + 1
```

当 `x = 0`：

```text
y = 1
```

所以截距是 1。

### 2.4 线性模型

AI 中最简单的模型：

```text
y = wx + b
```

这和一次函数完全同形。

区别只是名字变了：

- 数学里常写 `k`。
- 机器学习里常写 `w`，表示权重。

### 2.5 Python 画图

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)
y = 2 * x + 1

plt.plot(x, y)
plt.grid(True)
plt.show()
```

### 2.6 练习

1. `y = 3x + 2`，当 `x = 4`，`y` 是多少？
2. `y = -x + 5` 的斜率是多少？
3. `y = 2x - 3` 的截距是多少？
4. 如果一条直线斜率为正，它大致向哪个方向倾斜？

答案：

```text
1. 14
2. -1
3. -3
4. 从左下到右上。
```

## 第 3 章：二次函数

### 3.1 形式

二次函数：

```text
y = ax^2 + bx + c
```

其中 `a ≠ 0`。如果 `a = 0`，这一项就不是二次项，函数会退化成一次函数。

最简单的例子：

```text
y = x^2
```

图像是一条抛物线。

### 3.2 开口方向

`a` 决定抛物线开口方向。

```text
a > 0：开口向上，有最小值。
a < 0：开口向下，有最大值。
```

下面这个动态图只改变 `a`，你可以观察抛物线怎样从向下开口变成向上开口。

![二次函数开口变化动态图]({{ '/textbook/assets/functions/quadratic-opening.gif' | relative_url }})

### 3.3 顶点

二次函数有最大值或最小值。

例如：

```text
y = x^2
```

最小值是 0，在 `x = 0` 处取得。

这个点叫顶点。

### 3.4 AI 中的平方

均方误差：

```text
MSE = 平均((预测值 - 真实值)^2)
```

它用平方放大大误差。

Python：

```python
import numpy as np

y_true = np.array([3, 5, 7])
y_pred = np.array([2, 5, 10])
mse = np.mean((y_pred - y_true) ** 2)
print(mse)
```

## 第 4 章：反比例函数、绝对值函数和分段函数

这一章补三个常见但容易被传统教材讲散的函数。它们后面会反复出现在算法、优化和图像处理中。

### 4.1 反比例函数

反比例函数常见形式：

```text
y = k / x
```

其中 `x ≠ 0`。

例如：

```text
y = 1 / x
```

当 `x` 越接近 0，函数值变化越剧烈。

这个函数能帮助你理解：

- 除法里的“不能除以 0”。
- 对数导数 `1/x`。
- 物理和工程里的反比关系。

### 4.2 绝对值函数

绝对值表示一个数到 0 的距离。

```text
|3| = 3
|-3| = 3
```

绝对值函数：

```text
y = |x|
```

它的图像像一个 V。

在误差度量中，平均绝对误差 MAE 会用到绝对值：

```text
MAE = 平均(|预测值 - 真实值|)
```

### 4.3 分段函数

分段函数是“不同范围用不同规则”的函数。

例如：

```text
f(x) = 0, x <= 0
f(x) = x, x > 0
```

这就是 ReLU 激活函数：

```text
ReLU(x) = max(0, x)
```

神经网络里非常常见。

阈值函数也是分段函数：

```text
像素值 <= 阈值 -> 0
像素值 > 阈值 -> 255
```

### 4.4 Python

```python
def relu(x):
    return max(0, x)

for x in [-2, -1, 0, 1, 2]:
    print(x, relu(x))
```

## 第 5 章：指数函数

### 5.1 形式

```text
y = a^x
```

在初等实函数中，一般要求：

```text
a > 0 且 a ≠ 1
```

如果 `a = 1`，那么 `1^x` 永远等于 1，不再体现指数变化。

例如：

```text
y = 2^x
```

当 `x` 增大时，`y` 增长很快。

### 5.2 常见底数 e

数学和 AI 中经常出现 `e`：

```text
e ≈ 2.71828
```

指数函数：

```text
e^x
```

在概率分布、softmax、神经网络中经常出现。

### 5.3 Python

```python
import math

print(math.exp(1))
print(math.exp(2))
```

## 第 6 章：对数函数

### 6.1 对数是什么

对数回答的问题是：

```text
底数要多少次方，才能得到这个数？
```

例如：

```text
log2(8) = 3
```

因为：

```text
2^3 = 8
```

对数函数里，底数也有要求：

```text
底数 a > 0 且 a ≠ 1
真数 x > 0
```

所以 `log2(8)` 有意义，但 `log2(-8)` 在实数范围内没有意义。

### 6.2 对数和指数互逆

```text
log_a(a^x) = x
```

这里默认 `a > 0` 且 `a ≠ 1`。

指数函数和对数函数互为反函数。图像上，它们关于 `y = x` 对称。

![指数函数和对数函数互逆]({{ '/textbook/assets/functions/exp-log-inverse.png' | relative_url }})

### 6.3 AI 中的对数

交叉熵会用到 `log`。

直觉：

- 真实类别的预测概率越高，损失越小。
- 真实类别的预测概率越低，损失越大。

例子：

```python
import math

p_good = 0.9
p_bad = 0.1
print(-math.log(p_good))
print(-math.log(p_bad))
```

## 第 7 章：三角函数

### 7.1 角度和弧度

编程里常用弧度：

```text
180° = π
90° = π/2
360° = 2π
```

### 7.2 sin、cos、tan

在直角三角形中：

```text
sin = 对边 / 斜边
cos = 邻边 / 斜边
tan = 对边 / 邻边
```

注意：`tan` 要求邻边不为 0。换成角度语言，`90°`、`270°` 这类位置的 `tan` 在实数里没有定义。

另一个更适合图像处理和信号处理的理解方式是单位圆：

```text
cosθ 是点的横坐标。
sinθ 是点的纵坐标。
```

![单位圆三角函数动态图]({{ '/textbook/assets/functions/unit-circle-trig.gif' | relative_url }})

### 7.3 图像处理中为什么用三角函数

图像旋转：

```text
x' = x cosθ - y sinθ
y' = x sinθ + y cosθ
```

这个公式默认使用数学坐标系：`x` 向右，`y` 向上，正角度是逆时针。图像处理中常见坐标是左上角为原点，`y` 向下，所以实际写 OpenCV 代码时要注意方向约定。

傅里叶变换也建立在正弦和余弦上。

Python：

```python
import math

theta = math.pi / 2
print(math.sin(theta))
print(math.cos(theta))
```

## 第 8 章：数列和求和

### 8.1 数列

数列是一串有顺序的数：

```text
1, 2, 3, 4, 5
```

### 8.2 等差数列

相邻两项差相同：

```text
2, 5, 8, 11
```

差是 3。

### 8.3 等比数列

相邻两项倍数相同：

```text
2, 4, 8, 16
```

公比是 2。

### 8.4 求和符号

```text
Σ xi
```

表示把所有 `xi` 加起来。

Python：

```python
xs = [1, 2, 3, 4, 5]
print(sum(xs))
```

算法复杂度、统计、机器学习里都会见到求和。

## 第 9 章：不等式和阈值函数

### 9.1 基本不等式

```text
x > 3
x <= 10
```

表示范围。

### 9.2 区间

```text
0 <= x <= 1
```

表示 `x` 在 0 和 1 之间。

概率常常在这个区间：

```text
0 <= p <= 1
```

### 9.3 阈值判断

图像二值化：

```text
如果 像素值 > 阈值，设为白色。
否则，设为黑色。
```

这个过程也可以看成一个函数：输入灰度值，输出 0 或 255。

![阈值函数示意图]({{ '/textbook/assets/functions/threshold-function.png' | relative_url }})

Python：

```python
pixel = 180
threshold = 128
value = 255 if pixel > threshold else 0
print(value)
```

## 第 10 章：本册综合练习

1. `f(x) = 2x + 3`，求 `f(5)`。
2. `y = -3x + 1` 的斜率是多少？
3. `2^4` 等于多少？
4. `log2(16)` 等于多少？
5. 概率 `p` 的合理范围是什么？
6. 图像旋转为什么需要 `sin` 和 `cos`？
7. 阈值函数为什么适合解释图像二值化？
8. `ReLU(x) = max(0, x)` 为什么可以看成分段函数？

答案：

```text
1. 13
2. -3
3. 16
4. 4
5. 0 <= p <= 1
6. 因为旋转后的坐标需要用角度的正弦和余弦来计算。
7. 因为二值化就是根据输入像素值是否超过阈值，输出黑或白。
8. 因为 `x <= 0` 时输出 0，`x > 0` 时输出 x，不同范围使用不同规则。
```

## 第 11 章：高中数学补充地图

本册重点讲函数与初等数学，但完整高中数学不只这些。

|---|---|---|

| 平面向量 | 第 2 册 | 线性代数和图像几何前置 |

```text

```

缺的高中分支，会在对应用途出现时补回来。

## 第 12 章：本册小结

这一册你需要真正记住：

- 函数是输入到输出的规则。
- 一次函数是最简单的线性模型。
- 斜率控制直线倾斜方向和倾斜程度。
- 二次函数和平方误差关系很近。
- 反比例函数提醒我们 `x = 0` 处可能无定义。
- 绝对值函数描述到 0 的距离。
- 分段函数是理解 ReLU 和阈值判断的桥梁。
- 指数和对数会出现在概率、损失函数、softmax 中。
- 三角函数会出现在旋转和信号处理中。
- 数列和求和是算法分析、统计、机器学习的基础。
- 不等式帮助我们描述范围、阈值和约束。

下一册进入向量和矩阵。那是 AI 与图像处理最重要的数学基础。
