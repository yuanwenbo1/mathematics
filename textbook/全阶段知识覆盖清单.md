# 全阶段知识覆盖清单

这份清单用于检查教材是否覆盖从儿童数学启蒙、小学、初中、高中、本科数学专业核心课到研究生数学方向的主要知识。

本教材另设“应用理解层”，用于说明数学方法在工程、科学、计算、金融、信息、管理等场景中的用途，但不把学习路线绑定到某一个工程领域。

标记说明：

```text
主干：必须学。
桥梁：为后续知识服务。
拓展：按方向选择。
```

## 当前缺口和后续扩写方向

完整第一版已经覆盖主干知识，但每个模块仍可继续加厚。

优先扩写顺序建议：

```text
1. 第前置册：增加更多小学阶段练习和图表练习。
2. 第0册：补初中方程、不等式、几何细节。
3. 第1册：补高中函数图像、三角函数、数列练习。
4. 第2册：补矩阵乘法和线性变换图解。
5. 第3册：补导数练习和梯度下降可视化。
6. 第6册：补 OpenCV 项目。
7. 第7册：补 NumPy 到 PyTorch 的过渡。
```

如果要扩成真正的“厚教材”，每个模块都应继续增加：

```text
讲解
例题
分级练习
答案
Python 实验
小项目
常见错误
```
