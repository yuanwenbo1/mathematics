# 第 0 册：数学重新启动

这一册的目标不是让你变成数学高手，而是把已经生锈的基础工具重新拿起来。

你后面要走数学专业路线，也会看到数学在工程、科学、计算、金融、信息等场景中的应用。真正需要的不是压轴题技巧，而是这些能力：

- 看懂数学符号。
- 会处理变量和表达式。
- 理解方程是什么意思。
- 知道函数是输入和输出的关系。
- 能把数学关系翻译成图、表、文字、公式或代码。

## 第 1 章：数和运算

### 1.1 常见的数

数学里最基础的对象是数。

| 类型 | 例子 | 用途 |
|---|---|---|
| 自然数 | 0, 1, 2, 3 | 计数 |
| 整数 | -2, -1, 0, 1 | 表示正负变化 |
| 小数 | 0.5, 3.14 | 表示连续数量 |
| 分数 | 1/2, 3/4 | 表示比例 |
| 百分数 | 20% | 表示每 100 份中有多少份 |

在编程里：

```python
a = 3
b = -2
c = 0.5
d = 20 / 100
```

### 1.2 运算顺序

一般顺序：

```text
括号 > 幂运算 > 乘除 > 加减
```

例子：

```text
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
```

Python 中一样：

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

### 1.3 正数和负数

正数可以理解为增加、向右、向上、盈利。

负数可以理解为减少、向左、向下、亏损。

例如：

```text
+100 表示收入 100
-50 表示支出 50
```

图像处理中，梯度也有正负：

```text
亮度从暗到亮：梯度为正
亮度从亮到暗：梯度为负
```

### 1.4 分数、小数、百分数

```text
1/2 = 0.5
1/4 = 0.25
3/4 = 0.75
50% = 0.5
20% = 0.2
```

算法评估中常见：

```text
准确率 = 预测正确数量 / 总数量
85 / 100 = 85%
```

### 1.5 幂运算

幂运算是重复相乘：

```text
2^3 = 2 * 2 * 2 = 8
10^3 = 1000
```

Python 写法：

```python
print(2 ** 3)
print(10 ** 3)
```

AI 中经常见到平方误差：

```text
(预测值 - 真实值)^2
```

平方可以把正误差和负误差都变成非负数，并且会放大大误差。

### 1.6 根号

根号和平方相反：

```text
√9 = 3
√16 = 4
```

注意：`√` 默认表示算术平方根，也就是非负的那个结果。

所以：

```text
√49 = 7
```

但如果题目写的是：

```text
x^2 = 49
```

那么解是：

```text
x = 7 或 x = -7
```

也可以写成：

```text
x = ±7
```

区别：

```text
√49 是一个数，默认取非负结果。
x^2 = 49 是一个方程，要找所有平方后等于 49 的 x。
```

图像处理中，边缘强度常写成：

```text
边缘强度 = √(gx^2 + gy^2)
```

这里的结果表示强度，强度不能是负数，所以取算术平方根。

### 1.7 本章练习

1. `3 + 4 * 5`
2. `(3 + 4) * 5`
3. `35%` 写成小数。
4. `2^5`
5. `√49`
6. 方程 `x^2 = 49` 的解是什么？
7. 如果 `gx = 6`，`gy = 8`，求 `√(gx^2 + gy^2)`。

答案：

```text
1. 23
2. 35
3. 0.35
4. 32
5. 7
6. x = ±7
7. 10
```

## 第 2 章：变量和代数式

### 2.1 变量

变量就是可以变化的数。

例如：

```text
price = 单价
count = 数量
total = 总价
```

那么：

```text
total = price * count
```

Python：

```python
price = 5
count = 3
total = price * count
print(total)
```

### 2.2 代数式

含有变量的式子叫代数式：

```text
2x + 3
x^2 + 1
3a + 2b
```

代数式不是一个固定数字，而是一套计算规则。

当 `x = 4`：

```text
2x + 3 = 2 * 4 + 3 = 11
```

### 2.3 同类项合并

```text
2x + 3x = 5x
4a + 2b + 3a = 7a + 2b
```

不同变量不能随便合并：

```text
2x + 3y
```

### 2.4 AI 中的代数式

最简单的线性模型：

```text
y = wx + b
```

含义：

- `x` 是输入。
- `w` 是权重。
- `b` 是偏置。
- `y` 是输出。

这就是后面线性回归、神经网络一层的原型。

### 2.5 本章练习

1. 当 `x = 3`，`2x + 5` 等于多少？
2. 当 `x = 4`，`x^2 + 1` 等于多少？
3. 化简 `3a + 2a`。
4. 化简 `4x + 3y + 2x`。
5. 如果 `y = 2x + 1`，当 `x = 10`，`y` 是多少？

答案：

```text
1. 11
2. 17
3. 5a
4. 6x + 3y
5. 21
```

## 第 3 章：方程

### 3.1 方程是什么

方程就是含有未知数的等式。

```text
x + 3 = 10
```

意思是：什么数加 3 等于 10？

答案：

```text
x = 7
```

### 3.2 解方程的核心

等式两边做同样的操作，等式仍然成立。

```text
x + 3 = 10
x = 10 - 3
x = 7
```

再看：

```text
2x = 12
x = 12 / 2
x = 6
```

### 3.3 方程为什么重要

软件和 AI 里大量问题都可以看成：

```text
已知一些条件，求未知量。
```

例子：

- 图像矫正：求一个几何变换。
- 机器学习：求一组模型参数。
- 算法问题：根据约束找到满足条件的解。

### 3.4 一元一次方程

形式：

```text
ax + b = c
```

例子：

```text
3x + 2 = 14
3x = 12
x = 4
```

### 3.5 本章练习

1. `x + 5 = 12`
2. `2x = 18`
3. `3x + 2 = 14`
4. `x / 4 = 6`
5. `5x - 3 = 22`

答案：

```text
1. x = 7
2. x = 9
3. x = 4
4. x = 24
5. x = 5
```

## 第 4 章：比例、百分比和单位

### 4.1 比例

比例描述“两个量之间的倍数关系”。

```text
a:b = 2:3
```

表示 `a` 和 `b` 的比例是 2 比 3。

如果总量是 50，按 2:3 分：

```text
总份数 = 2 + 3 = 5
a = 50 * 2/5 = 20
b = 50 * 3/5 = 30
```

### 4.2 增长率

```text
增长率 = (新值 - 旧值) / 旧值
```

例子：

```text
旧值 = 100
新值 = 120
增长率 = (120 - 100) / 100 = 20%
```

### 4.3 折扣

```text
八折 = 原价 * 0.8
七五折 = 原价 * 0.75
```

### 4.4 单位换算

图像处理中常见：

```text
1 KB = 1024 B
1 MB = 1024 KB
```

速度中常见：

```text
1 m/s = 3.6 km/h
```

### 4.5 本章练习

1. 80 按 3:5 分，两个数分别是多少？
2. 从 200 增长到 250，增长率是多少？
3. 100 元打 75 折是多少钱？
4. 2 MB 等于多少 KB？

答案：

```text
1. 30 和 50
2. 25%
3. 75 元
4. 2048 KB
```

## 第 5 章：坐标系

### 5.1 坐标

二维坐标写成：

```text
(x, y)
```

例如点 `(3, 2)` 表示：

- 横向走 3。
- 纵向走 2。

图像中的像素也有坐标：

```text
(列, 行)
```

常见约定是左上角为 `(0, 0)`，向右 `x` 增大，向下 `y` 增大。

### 5.2 两点距离

点 `A(x1, y1)` 和点 `B(x2, y2)` 的距离：

```text
d = √((x2 - x1)^2 + (y2 - y1)^2)
```

例子：

```text
A = (0, 0)
B = (3, 4)
d = √(3^2 + 4^2) = 5
```

### 5.3 坐标在图像处理中的用途

- 描述像素位置。
- 计算两点距离。
- 做旋转、缩放、裁剪。
- 做透视矫正。
- 找轮廓和目标框。

### 5.4 Python 小实验

```python
import math

x1, y1 = 0, 0
x2, y2 = 3, 4
d = math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
print(d)
```

## 第 10 章：给小朋友的算术到代数桥梁

这一章适合已经会基本加减乘除，但刚开始接触未知数、方程和几何的小朋友。

### 10.1 从空格到未知数

孩子一开始不一定要马上接受 `x`。

可以先写：

```text
□ + 3 = 10
```

问：

```text
什么数加 3 等于 10？
```

答案是：

```text
□ = 7
```

然后再告诉孩子：

```text
数学里常用 x 表示这个不知道的数。
```

所以：

```text
x + 3 = 10
```

和：

```text
□ + 3 = 10
```

意思一样。

### 10.2 等号不是“算出答案”

很多小朋友会把等号理解成“后面写答案”。

其实等号的意思是：

```text
左边和右边一样多。
```

例如：

```text
3 + 4 = 2 + 5
```

左右都等于 7，所以这个等式成立。

练习：

1. `6 + 2 = 5 + □`
2. `10 - 3 = □ + 2`
3. `4 * 3 = 6 + □`

答案：

```text
1. □ = 3
2. □ = 5
3. □ = 6
```

### 10.3 用天平理解方程

方程像一架天平。

```text
x + 2 = 8
```

表示左边和右边一样重。

如果两边同时减去 2：

```text
x + 2 - 2 = 8 - 2
x = 6
```

天平仍然平衡。

这就是解方程的核心。

### 10.4 应用题翻译四步

遇到应用题，不要急着算。

按四步来：

```text
第一步：找已知量。
第二步：找要求什么。
第三步：找关系。
第四步：写算式或方程。
```

例子：

```text
小明有一些贴纸，又买了 8 张，现在一共有 20 张。小明原来有多少张？
```

翻译：

```text
原来的贴纸数 + 8 = 20
x + 8 = 20
x = 12
```

### 10.5 线段图

线段图能帮助孩子看懂数量关系。

例子：

```text
小红有 12 颗糖，小明比小红多 5 颗。小明有多少颗？
```

线段图：

```text
小红：------------
小明：------------+++++
```

算式：

```text
12 + 5 = 17
```

如果题目是：

```text
小明有 17 颗糖，比小红多 5 颗。小红有多少颗？
```

算式：

```text
17 - 5 = 12
```

同一个关系，可以问不同未知量。

## 第 11 章：初等几何加厚

### 11.1 角

角可以理解为两条线张开的大小。

常见角：

```text
锐角：小于 90°
直角：等于 90°
钝角：大于 90° 小于 180°
平角：180°
周角：360°
```

生活例子：

```text
书本的角通常是直角。
钟表 3 点整时，时针和分针成直角。
```

### 11.2 平行和垂直

平行：

```text
两条线一直不相交。
```

垂直：

```text
两条线相交成直角。
```

生活例子：

```text
作业本上的横线通常互相平行。
桌面边和桌腿大致垂直。
```

### 11.3 三角形

三角形有三条边、三个角。

常见三角形：

```text
等边三角形：三条边一样长。
等腰三角形：有两条边一样长。
直角三角形：有一个角是 90°。
```

直角三角形以后会连接到勾股定理：

```text
a^2 + b^2 = c^2
```

### 11.4 四边形

常见四边形：

```text
正方形
长方形
平行四边形
梯形
菱形
```

先观察：

```text
有没有平行边？
有没有直角？
边是否一样长？
```

### 11.5 圆

圆的核心词：

```text
圆心
半径
直径
周长
面积
```

关系：

```text
直径 = 2 * 半径
```

圆周率：

```text
π ≈ 3.14
```

小学阶段先知道它是一个固定比例，不必急着证明。

## 第 12 章：整数、倍数和因数

### 12.1 偶数和奇数

偶数能被 2 整除。

```text
0, 2, 4, 6, 8, 10...
```

奇数不能被 2 整除。

```text
1, 3, 5, 7, 9...
```

### 12.2 倍数

如果一个数可以由另一个数乘整数得到，它就是倍数。

```text
3 的倍数：3, 6, 9, 12, 15...
```

### 12.3 因数

如果一个数能整除另一个数，它就是因数。

例如：

```text
12 = 3 * 4
```

所以 `3` 和 `4` 都是 `12` 的因数。

12 的因数有：

```text
1, 2, 3, 4, 6, 12
```

### 12.4 质数和合数

质数只有两个正因数：1 和它自己。

例如：

```text
2, 3, 5, 7, 11, 13
```

合数有超过两个正因数。

例如：

```text
4, 6, 8, 9, 10, 12
```

注意：`1` 既不是质数，也不是合数。

## 第 13 章：分数再加厚

### 13.1 分数的三个意思

分数至少有三个意思：

```text
整体的一部分：半个苹果。
除法结果：1 / 2。
比例关系：男生占全班的 1/2。
```

### 13.2 同分母分数加减

```text
1/5 + 2/5 = 3/5
```

分母不变，分子相加。

```text
4/7 - 1/7 = 3/7
```

分母不变，分子相减。

### 13.3 等值分数

```text
1/2 = 2/4 = 3/6 = 4/8
```

可以用切蛋糕理解：

```text
切成 2 份拿 1 份
切成 4 份拿 2 份
切成 8 份拿 4 份
```

拿到的大小一样。

### 13.4 分数比较

同分母：

```text
3/8 > 2/8
```

同分子：

```text
1/3 > 1/5
```

因为同样拿 1 份，分得越细，每份越小。

## 第 14 章：小朋友综合练习

1. `48` 里面有几个十，几个一？

答案：

1. 4 个十，8 个一
