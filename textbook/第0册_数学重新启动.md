# 初中数学全课程

本册面向所有自学七至九年级数学的学生，也适合需要查漏补缺的学习者。内容按知识依赖而不是某一版本教材的学期顺序组织，完整覆盖初中阶段的数与式、方程与不等式、函数、图形与几何、统计与概率、综合与实践。

学习目标不是只记解题模板，而是建立这些可以迁移的能力：

- 看懂数学符号。
- 会处理变量和表达式。
- 理解方程是什么意思。
- 知道函数是输入和输出的关系。
- 能把数学关系翻译成图、表、文字、公式或代码。

## 本册连续学习安排

本册前半部分用于从算术过渡到代数，后半部分系统覆盖初中课程。推荐顺序不是简单从第 1 章连续读到第 21 章，而是按知识依赖分段：

## 第 1 章：数和运算

### 1.1 常见的数

数学里最基础的对象是数。

| 类型 | 例子 | 用途 |
|---|---|---|
| 自然数 | 0, 1, 2, 3 | 计数 |
| 整数 | -2, -1, 0, 1 | 表示正负变化 |
| 小数 | 0.5, 3.14 | 表示连续数量 |
| 分数 | 1/2, 3/4 | 表示比例 |
| 百分数 | 20% | 表示每 100 份中有多少份 |

在编程里：

```python
a = 3
b = -2
c = 0.5
d = 20 / 100
```

### 1.2 运算顺序

一般顺序：

```text
括号 > 幂运算 > 乘除 > 加减
```

例子：

```text
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
```

Python 中一样：

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

### 1.3 正数和负数

正数可以理解为增加、向右、向上、盈利。

负数可以理解为减少、向左、向下、亏损。

例如：

```text
+100 表示收入 100
-50 表示支出 50
```

图像处理中，梯度也有正负：

```text
亮度从暗到亮：梯度为正
亮度从亮到暗：梯度为负
```

### 1.4 分数、小数、百分数

```text
1/2 = 0.5
1/4 = 0.25
3/4 = 0.75
50% = 0.5
20% = 0.2
```

算法评估中常见：

```text
准确率 = 预测正确数量 / 总数量
85 / 100 = 85%
```

### 1.5 幂运算

幂运算是重复相乘：

```text
2^3 = 2 * 2 * 2 = 8
10^3 = 1000
```

Python 写法：

```python
print(2 ** 3)
print(10 ** 3)
```

AI 中经常见到平方误差：

```text
(预测值 - 真实值)^2
```

平方可以把正误差和负误差都变成非负数，并且会放大大误差。

### 1.6 根号

根号和平方相反：

```text
√9 = 3
√16 = 4
```

注意：`√` 默认表示算术平方根，也就是非负的那个结果。

所以：

```text
√49 = 7
```

但如果题目写的是：

```text
x^2 = 49
```

那么解是：

```text
x = 7 或 x = -7
```

也可以写成：

```text
x = ±7
```

区别：

```text
√49 是一个数，默认取非负结果。
x^2 = 49 是一个方程，要找所有平方后等于 49 的 x。
```

图像处理中，边缘强度常写成：

```text
边缘强度 = √(gx^2 + gy^2)
```

这里的结果表示强度，强度不能是负数，所以取算术平方根。

### 1.7 本章练习

1. `3 + 4 * 5`
2. `(3 + 4) * 5`
3. `35%` 写成小数。
4. `2^5`
5. `√49`
6. 方程 `x^2 = 49` 的解是什么？
7. 如果 `gx = 6`，`gy = 8`，求 `√(gx^2 + gy^2)`。

答案：

```text
1. 23
2. 35
3. 0.35
4. 32
5. 7
6. x = ±7
7. 10
```

## 第 2 章：变量和代数式

### 2.1 变量

变量就是可以变化的数。

例如：

```text
price = 单价
count = 数量
total = 总价
```

那么：

```text
total = price * count
```

Python：

```python
price = 5
count = 3
total = price * count
print(total)
```

### 2.2 代数式

含有变量的式子叫代数式：

```text
2x + 3
x^2 + 1
3a + 2b
```

代数式不是一个固定数字，而是一套计算规则。

当 `x = 4`：

```text
2x + 3 = 2 * 4 + 3 = 11
```

### 2.3 同类项合并

```text
2x + 3x = 5x
4a + 2b + 3a = 7a + 2b
```

不同变量不能随便合并：

```text
2x + 3y
```

### 2.4 AI 中的代数式

最简单的线性模型：

```text
y = wx + b
```

含义：

- `x` 是输入。
- `w` 是权重。
- `b` 是偏置。
- `y` 是输出。

这就是后面线性回归、神经网络一层的原型。

### 2.5 本章练习

1. 当 `x = 3`，`2x + 5` 等于多少？
2. 当 `x = 4`，`x^2 + 1` 等于多少？
3. 化简 `3a + 2a`。
4. 化简 `4x + 3y + 2x`。
5. 如果 `y = 2x + 1`，当 `x = 10`，`y` 是多少？

答案：

```text
1. 11
2. 17
3. 5a
4. 6x + 3y
5. 21
```

## 第 3 章：方程

### 3.1 方程是什么

方程就是含有未知数的等式。

```text
x + 3 = 10
```

意思是：什么数加 3 等于 10？

答案：

```text
x = 7
```

### 3.2 解方程的核心

等式两边做同样的操作，等式仍然成立。

```text
x + 3 = 10
x = 10 - 3
x = 7
```

再看：

```text
2x = 12
x = 12 / 2
x = 6
```

### 3.3 方程为什么重要

软件和 AI 里大量问题都可以看成：

```text
已知一些条件，求未知量。
```

例子：

- 图像矫正：求一个几何变换。
- 机器学习：求一组模型参数。
- 算法问题：根据约束找到满足条件的解。

### 3.4 一元一次方程

形式：

```text
ax + b = c
```

例子：

```text
3x + 2 = 14
3x = 12
x = 4
```

### 3.5 本章练习

1. `x + 5 = 12`
2. `2x = 18`
3. `3x + 2 = 14`
4. `x / 4 = 6`
5. `5x - 3 = 22`

答案：

```text
1. x = 7
2. x = 9
3. x = 4
4. x = 24
5. x = 5
```

## 第 4 章：比例、百分比和单位

### 4.1 比例

比例描述“两个量之间的倍数关系”。

```text
a:b = 2:3
```

表示 `a` 和 `b` 的比例是 2 比 3。

如果总量是 50，按 2:3 分：

```text
总份数 = 2 + 3 = 5
a = 50 * 2/5 = 20
b = 50 * 3/5 = 30
```

### 4.2 增长率

```text
增长率 = (新值 - 旧值) / 旧值
```

例子：

```text
旧值 = 100
新值 = 120
增长率 = (120 - 100) / 100 = 20%
```

### 4.3 折扣

```text
八折 = 原价 * 0.8
七五折 = 原价 * 0.75
```

### 4.4 单位换算

图像处理中常见：

```text
1 KB = 1024 B
1 MB = 1024 KB
```

速度中常见：

```text
1 m/s = 3.6 km/h
```

### 4.5 本章练习

1. 80 按 3:5 分，两个数分别是多少？
2. 从 200 增长到 250，增长率是多少？
3. 100 元打 75 折是多少钱？
4. 2 MB 等于多少 KB？

答案：

```text
1. 30 和 50
2. 25%
3. 75 元
4. 2048 KB
```

## 第 5 章：坐标系

### 5.1 坐标

二维坐标写成：

```text
(x, y)
```

例如点 `(3, 2)` 表示：

- 横向走 3。
- 纵向走 2。

图像中的像素也有坐标：

```text
(列, 行)
```

常见约定是左上角为 `(0, 0)`，向右 `x` 增大，向下 `y` 增大。

### 5.2 两点距离

点 `A(x1, y1)` 和点 `B(x2, y2)` 的距离：

```text
d = √((x2 - x1)^2 + (y2 - y1)^2)
```

例子：

```text
A = (0, 0)
B = (3, 4)
d = √(3^2 + 4^2) = 5
```

### 5.3 坐标在图像处理中的用途

- 描述像素位置。
- 计算两点距离。
- 做旋转、缩放、裁剪。
- 做透视矫正。
- 找轮廓和目标框。

### 5.4 Python 小实验

```python
import math

x1, y1 = 0, 0
x2, y2 = 3, 4
d = math.sqrt((x2 - x1) ** 2 + (y2 - y1) ** 2)
print(d)
```

### 6.1 点、线、面

- 点：位置。
- 线：点运动形成的轨迹。

图像中的目标框就是矩形区域。

### 6.2 面积

矩形面积：

```text
S = 长 * 宽
```

圆面积：

```text
S = πr^2
```

### 6.3 角度和弧度

角度：

```text
90° 是直角
180° 是平角
360° 是一圈
```

弧度：

```text
180° = π 弧度
```

## 第 10 章：给小朋友的算术到代数桥梁

这一章适合已经会基本加减乘除，但刚开始接触未知数、方程和几何的小朋友。

### 10.1 从空格到未知数

孩子一开始不一定要马上接受 `x`。

可以先写：

```text
□ + 3 = 10
```

问：

```text
什么数加 3 等于 10？
```

答案是：

```text
□ = 7
```

然后再告诉孩子：

```text
数学里常用 x 表示这个不知道的数。
```

所以：

```text
x + 3 = 10
```

和：

```text
□ + 3 = 10
```

意思一样。

### 10.2 等号不是“算出答案”

很多小朋友会把等号理解成“后面写答案”。

其实等号的意思是：

```text
左边和右边一样多。
```

例如：

```text
3 + 4 = 2 + 5
```

左右都等于 7，所以这个等式成立。

练习：

1. `6 + 2 = 5 + □`
2. `10 - 3 = □ + 2`
3. `4 * 3 = 6 + □`

答案：

```text
1. □ = 3
2. □ = 5
3. □ = 6
```

### 10.3 用天平理解方程

方程像一架天平。

```text
x + 2 = 8
```

表示左边和右边一样重。

如果两边同时减去 2：

```text
x + 2 - 2 = 8 - 2
x = 6
```

天平仍然平衡。

这就是解方程的核心。

### 10.4 应用题翻译四步

遇到应用题，不要急着算。

按四步来：

```text
第一步：找已知量。
第二步：找要求什么。
第三步：找关系。
第四步：写算式或方程。
```

例子：

```text
小明有一些贴纸，又买了 8 张，现在一共有 20 张。小明原来有多少张？
```

翻译：

```text
原来的贴纸数 + 8 = 20
x + 8 = 20
x = 12
```

### 10.5 线段图

线段图能帮助孩子看懂数量关系。

例子：

```text
小红有 12 颗糖，小明比小红多 5 颗。小明有多少颗？
```

线段图：

```text
小红：------------
小明：------------+++++
```

算式：

```text
12 + 5 = 17
```

如果题目是：

```text
小明有 17 颗糖，比小红多 5 颗。小红有多少颗？
```

算式：

```text
17 - 5 = 12
```

同一个关系，可以问不同未知量。

## 第 11 章：初等几何加厚

### 11.1 角

角可以理解为两条线张开的大小。

常见角：

```text
锐角：小于 90°
直角：等于 90°
钝角：大于 90° 小于 180°
平角：180°
周角：360°
```

生活例子：

```text
书本的角通常是直角。
钟表 3 点整时，时针和分针成直角。
```

### 11.2 平行和垂直

平行：

```text
两条线一直不相交。
```

垂直：

```text
两条线相交成直角。
```

生活例子：

```text
作业本上的横线通常互相平行。
桌面边和桌腿大致垂直。
```

### 11.3 三角形

三角形有三条边、三个角。

常见三角形：

```text
等边三角形：三条边一样长。
等腰三角形：有两条边一样长。
直角三角形：有一个角是 90°。
```

直角三角形以后会连接到勾股定理：

```text
a^2 + b^2 = c^2
```

### 11.4 四边形

常见四边形：

```text
正方形
长方形
平行四边形
梯形
菱形
```

先观察：

```text
有没有平行边？
有没有直角？
边是否一样长？
```

### 11.5 圆

圆的核心词：

```text
圆心
半径
直径
周长
面积
```

关系：

```text
直径 = 2 * 半径
```

圆周率：

```text
π ≈ 3.14
```

小学阶段先知道它是一个固定比例，不必急着证明。

## 第 12 章：整数、倍数和因数

### 12.1 偶数和奇数

偶数能被 2 整除。

```text
0, 2, 4, 6, 8, 10...
```

奇数不能被 2 整除。

```text
1, 3, 5, 7, 9...
```

### 12.2 倍数

如果一个数可以由另一个数乘整数得到，它就是倍数。

```text
3 的倍数：3, 6, 9, 12, 15...
```

### 12.3 因数

如果一个数能整除另一个数，它就是因数。

例如：

```text
12 = 3 * 4
```

所以 `3` 和 `4` 都是 `12` 的因数。

12 的因数有：

```text
1, 2, 3, 4, 6, 12
```

### 12.4 质数和合数

质数只有两个正因数：1 和它自己。

例如：

```text
2, 3, 5, 7, 11, 13
```

合数有超过两个正因数。

例如：

```text
4, 6, 8, 9, 10, 12
```

注意：`1` 既不是质数，也不是合数。

## 第 13 章：分数再加厚

### 13.1 分数的三个意思

分数至少有三个意思：

```text
整体的一部分：半个苹果。
除法结果：1 / 2。
比例关系：男生占全班的 1/2。
```

### 13.2 同分母分数加减

```text
1/5 + 2/5 = 3/5
```

分母不变，分子相加。

```text
4/7 - 1/7 = 3/7
```

分母不变，分子相减。

### 13.3 等值分数

```text
1/2 = 2/4 = 3/6 = 4/8
```

可以用切蛋糕理解：

```text
切成 2 份拿 1 份
切成 4 份拿 2 份
切成 8 份拿 4 份
```

拿到的大小一样。

### 13.4 分数比较

同分母：

```text
3/8 > 2/8
```

同分子：

```text
1/3 > 1/5
```

因为同样拿 1 份，分得越细，每份越小。

## 第 14 章：小朋友综合练习

1. `48` 里面有几个十，几个一？
2. `7 + 8` 用凑十法怎么算？
3. `15 - 7` 用破十法怎么算？
4. `6 * 4` 可以表示几组几个？
5. 一本书 9 元，给 20 元，应找回多少元？
6. `□ + 6 = 14`，□ 是多少？
7. `5 + 4 = □ + 3`，□ 是多少？
8. 12 的因数有哪些？
9. `1/6 + 3/6` 等于多少？
10. 长 5、宽 2 的长方形，面积和周长分别是多少？

答案：

```text
1. 4 个十，8 个一
```

## 第 15 章：实数、整式、分式与二次根式

### 15.1 有理数与实数

有理数可以写成两个整数之比 `p/q`（`q != 0`），包括整数、有限小数和无限循环小数。不能写成这种形式的数叫无理数，例如 `√2`、`π`。有理数和无理数合称实数。

实数与数轴上的点一一对应。绝对值 `|a|` 表示数轴上点 `a` 到原点的距离，因此：

```text
|a| >= 0
|a| = |-a|
若 a >= 0，|a| = a
若 a < 0，|a| = -a
```

近似数必须说明精确程度。例如 `3.14` 精确到百分位；用近似值继续计算时，通常在最后一步再按要求取舍，避免误差过早累积。

### 15.2 幂、科学记数法与平方根

非零数的零次幂为 1，负整数指数表示倒数：

```text
a^m * a^n = a^(m+n)
(a^m)^n = a^(mn)
(ab)^n = a^n b^n
a^(-n) = 1/a^n  （a != 0）
```

科学记数法写成 `a * 10^n`，其中 `1 <= |a| < 10`。例如 `0.00042 = 4.2 * 10^(-4)`。

`√a` 只在 `a >= 0` 的实数范围内有意义，并表示非负平方根。`√(a^2) = |a|`，不能直接写成 `a`。

### 15.3 整式运算与因式分解

单项式和多项式统称整式。合并同类项只能合并字母部分完全相同的项。

```text
(a + b)^2 = a^2 + 2ab + b^2
(a - b)^2 = a^2 - 2ab + b^2
(a + b)(a - b) = a^2 - b^2
```

因式分解是把多项式写成若干整式乘积，常用方法包括提公因式、公式法和分组法。

例：

```text
2x^2 - 8 = 2(x^2 - 4) = 2(x - 2)(x + 2)
```

展开与因式分解互为逆过程，可以相互检验。

### 15.4 分式

形如 `A/B` 的式子叫分式，必须注明 `B != 0`。分式基本性质是分子、分母同乘或同除以同一个非零整式，分式值不变。

```text
1/x + 1/(x+1)
= (x+1)/(x(x+1)) + x/(x(x+1))
= (2x+1)/(x(x+1))
```

定义域限制为 `x != 0` 且 `x != -1`。约分不能消掉加法中的一项，例如 `(x+1)/x` 不能约成 1。

### 15.5 二次根式

当 `a >= 0` 时，`√a` 是二次根式。化简要把被开方数中的完全平方因数移到根号外：

```text
√12 = √(4*3) = 2√3
√8 + √18 = 2√2 + 3√2 = 5√2
```

只有化成最简二次根式后，被开方数相同的项才能合并。

### 15.6 本章验收

1. 将 `0.0000063` 写成科学记数法。
2. 化简 `(x+3)^2 - (x-3)(x+3)`。
3. 因式分解 `3x^2 - 12x`。
4. 化简 `√50 - √8`。
5. 写出分式 `(x+2)/(x^2-4)` 的取值限制并约分。

答案：`6.3*10^(-6)`；`6x+18`；`3x(x-4)`；`3√2`；`x != ±2`，在原限制下约为 `1/(x-2)`。

## 第 16 章：方程、方程组与不等式

### 16.1 一元一次方程与应用

解方程的依据是等式性质。应用题的关键是设未知数、找等量关系、列方程、求解、检验并作答。

例：某商品先提价 20%，再打八折，现价 192 元。设原价为 `x`：

```text
x * 1.2 * 0.8 = 192
0.96x = 192
x = 200
```

“提价 20% 再降价 20%”不会回到原价，因为两次百分比所依据的基数不同。

### 16.2 二元一次方程组

方程组的解必须同时满足所有方程。消元法把二元问题转化为一元问题。

```text
x + y = 10
2x - y = 5
```

两式相加得 `3x = 15`，所以 `x = 5, y = 5`。也可以把每个方程看成一条直线，方程组的解就是两条直线的交点。

### 16.3 一元二次方程

一般形式：

```text
ax^2 + bx + c = 0  （a != 0）
```

解法包括因式分解、配方法和求根公式：

```text
x = (-b ± √(b^2 - 4ac)) / (2a)
```

判别式 `Δ = b^2 - 4ac`：`Δ > 0` 有两个不相等实根，`Δ = 0` 有两个相等实根，`Δ < 0` 在实数范围内无根。

根与系数关系：若根为 `x1, x2`，则 `x1+x2=-b/a`，`x1x2=c/a`。

### 16.4 分式方程

解分式方程时先确定所有分母不为 0 的限制，再乘最简公分母去分母。去分母可能产生增根，所以必须把结果代回原方程检验。

例：

```text
1/x = 2/(x+3)，x != 0,-3
x + 3 = 2x
x = 3
```

代回原式成立，因此 `x = 3` 是解。

### 16.5 一元一次不等式与不等式组

不等式两边同时乘或除以负数时，不等号方向必须改变：

```text
-2x > 6
x < -3
```

解不等式组就是求各个解集的公共部分。把解集画在数轴上可以减少边界错误；空心点表示不包含端点，实心点表示包含端点。

### 16.6 本章验收

1. 解方程组 `2x+y=7, x-y=2`。
2. 解 `x^2-5x+6=0`。
3. 解不等式组 `x>1, 2x<=8`。
4. 为什么分式方程必须验根？

答案：`x=3,y=1`；`x=2 或 3`；`1<x<=4`；去分母改变了方程形式，可能加入使原分母为 0 的值。

## 第 17 章：初中函数

### 17.1 函数的三种表示

在一个变化过程中，如果给定 `x` 的一个允许取值，都有唯一的 `y` 与它对应，那么 `y` 是 `x` 的函数。函数可用列表、解析式和图像表示。

研究函数统一回答四个问题：定义域是什么、变量怎样对应、图像怎样变化、模型适合解决什么问题。

### 17.2 正比例和一次函数

```text
正比例函数：y = kx  （k != 0）
一次函数：y = kx + b  （k != 0）
```

`k` 决定增减和倾斜程度，`b` 是 `y` 轴截距。两点确定一条直线，斜率为 `(y2-y1)/(x2-x1)`（`x1 != x2`）。

一次函数可以解决固定费用加单位费用的问题。例如打车费 `y = 10 + 2.4x`，其中 10 是起步固定费用，2.4 是每千米增加费用。

### 17.3 反比例函数

```text
y = k/x  （k != 0，x != 0）
```

图像是双曲线。`k > 0` 时两支在第一、三象限；`k < 0` 时在第二、四象限。矩形面积固定时，长和宽构成反比例关系。

### 17.4 二次函数

```text
y = ax^2 + bx + c  （a != 0）
```

图像是抛物线，对称轴 `x = -b/(2a)`，顶点横坐标是 `-b/(2a)`。配方得到：

```text
y = a(x-h)^2 + k
```

顶点为 `(h,k)`。二次函数与一元二次方程相连：方程的实根就是抛物线与 `x` 轴交点的横坐标。

例：`y=-x^2+6x-5=-(x-3)^2+4`，最大值为 4，在 `x=3` 处取得。

### 17.5 函数建模步骤

```text
确定变量与单位
分析对应关系
选择函数类型
求参数
检查定义域和图像
解释结果及模型限制
```

不要把相关关系自动当成因果关系，也不要在样本范围之外随意外推。

### 17.6 本章验收

1. 直线经过 `(1,3)` 和 `(4,9)`，求解析式。
2. `y=-2x^2+8x-3` 的对称轴是什么？
3. 同样路程下，速度和时间是什么比例关系？说明条件。

答案：`y=2x+1`；`x=2`；路程固定且速度、时间为正时成反比例。

## 第 18 章：图形性质与几何证明

### 18.1 命题、定义与证明

命题由条件和结论组成。真命题需要证明，说明假命题只需一个反例。证明时不能把要证明的结论当作已知条件。

标准书写：

```text
已知：明确条件
求证：明确结论
证明：每一步写依据
```

### 18.2 相交线、平行线与角

对顶角相等，邻补角和为 180°。平行线的判定与性质要区分：

- 同位角相等、内错角相等或同旁内角互补，可以判定两直线平行。
- 两直线平行，可以推出同位角相等、内错角相等、同旁内角互补。

### 18.3 三角形与全等

三角形内角和为 180°，外角等于与它不相邻的两个内角之和。全等三角形的对应边、对应角相等，常用判定：SSS、SAS、ASA、AAS，以及直角三角形的 HL。

例：在 `△ABC` 与 `△DEF` 中，若 `AB=DE, AC=DF, ∠A=∠D`，则由 SAS 可证两三角形全等。必须保证这个角是两组已知边的夹角。

### 18.4 等腰三角形、勾股定理

等腰三角形两底角相等；反过来，有两个角相等的三角形是等腰三角形。直角三角形两直角边为 `a,b`，斜边为 `c`：

```text
a^2 + b^2 = c^2
```

逆定理也成立，可用三边关系判断直角三角形。勾股定理只适用于直角三角形。

### 18.5 相似三角形

相似图形形状相同、大小可以不同。三角形相似的常用判定：AA、两边成比例且夹角相等、三边成比例。

相似比为 `k` 时：周长比为 `k`，面积比为 `k^2`。利用同一时刻物体与影子的相似三角形，可以间接测高。

### 18.6 四边形

```text
平行四边形：两组对边分别平行
矩形：有一个角是直角的平行四边形
菱形：有一组邻边相等的平行四边形
正方形：既是矩形又是菱形
```

平行四边形的对边相等、对角相等、对角线互相平分。矩形对角线相等，菱形对角线互相垂直，正方形同时具有这些特殊性质。

### 18.7 圆

圆中常见对象包括弦、弧、圆心角、圆周角、切线。核心结论：

- 同弧所对的圆周角相等，圆周角等于同弧圆心角的一半。
- 直径所对的圆周角是直角。
- 切线垂直于经过切点的半径。
- 从圆外一点引圆的两条切线，切线长相等。

弧长与扇形面积：

```text
弧长 = n/360 * 2πr
扇形面积 = n/360 * πr^2
```

### 18.8 尺规作图与证明验收

应会用无刻度直尺和圆规完成：作线段等长、作角等大、作角平分线、作线段垂直平分线、过一点作已知直线的垂线。作图后要说明依据。

证明题：在平行四边形 `ABCD` 中，对角线交于 `O`。证明 `OA=OC` 且 `OB=OD`。

思路：由 `AB // CD` 得一组内错角相等，再用平行四边形对边相等证明两三角形全等，得到对应边相等。

## 第 19 章：图形变换、投影与坐标

### 19.1 平移、旋转、轴对称与中心对称

图形变换要追踪对应点。平移保持方向，旋转需要中心、方向和角度，轴对称需要对称轴。中心对称相当于绕中心旋转 180°。

坐标规律：

```text
关于 x 轴对称：(x,y) -> (x,-y)
关于 y 轴对称：(x,y) -> (-x,y)
关于原点对称：(x,y) -> (-x,-y)
向右平移 a：(x,y) -> (x+a,y)
```

### 19.2 视图与投影

从正面、左面、上面观察立体图形得到三视图。由视图还原物体时，要同时满足所有方向看到的轮廓和层数。中心投影的投射线从一点发出，平行投影的投射线互相平行；太阳光可近似看作平行投影。

### 19.3 坐标几何

坐标把几何问题转成代数问题。两点距离、中点坐标和图形变换是关键工具：

```text
d = √((x2-x1)^2 + (y2-y1)^2)
M = ((x1+x2)/2, (y1+y2)/2)
```

解题后还要回到图形解释代数结果，防止只算不看位置关系。

## 第 20 章：统计、概率与综合实践

### 20.1 调查、总体与样本

全面调查适合对象较少或必须精确的情形；抽样调查适合总体很大、调查具有破坏性或成本高的情形。样本要具有代表性，便利抽样可能产生偏差。

### 20.2 数据的中心与波动

- 平均数利用全部数据，易受极端值影响。
- 中位数把排序后的数据分成数量相等的两部分，较稳健。
- 众数是出现次数最多的数，可能不唯一。
- 方差和标准差描述数据相对平均数的波动大小。

```text
方差 = 每个数据与平均数之差的平方的平均数
标准差 = √方差
```

选择统计量要结合问题。例如收入差距很大时，中位数往往比平均数更能表示“典型收入”。

### 20.3 频数分布与统计图

数据较多时可以分组，制作频数分布表、频数分布直方图。组距和组数会影响图形细节，不能只凭图形外观下结论。扇形图表示比例，条形图比较类别，折线图观察时间变化，直方图表示连续区间内的频数分布。

### 20.4 随机事件与概率

必然事件概率为 1，不可能事件概率为 0，随机事件概率在 0 与 1 之间。等可能模型可用列举法或树状图：

例：同时抛两枚均匀硬币，样本空间为 `{正正, 正反, 反正, 反反}`，恰有一枚正面的概率是 `2/4=1/2`。

大量重复试验中，频率通常在概率附近波动。频率是试验结果，概率是随机现象的理论或模型特征。

### 20.5 综合实践项目

任选一个完成：

1. 调查校园每天产生的可回收垃圾，设计抽样方案、整理数据、选择统计图并提出建议。
2. 比较两种手机套餐，用一次函数建立总费用模型，求不同使用量下的选择区间。
3. 测量旗杆高度，用相似三角形说明方法、记录误差并分析误差来源。

项目报告必须包含问题、假设、变量与单位、数据、数学模型、计算、结论和局限。

## 初中专题：典型题精讲与易错诊断

本专题把代数、函数、几何和统计放到同一套解题流程中：先确认条件和定义域，再选择方法，最后用代入、图像、数量级或逻辑关系检查。

### 专题 1：因式分解不是解方程

**例题。** 解方程 `x^2-5x=0`。

先因式分解：

```text
x^2 - 5x = x(x-5)
x(x-5) = 0
```

两个因式的积为 0，所以至少有一个因式为 0：

```text
x = 0 或 x - 5 = 0
x = 0 或 x = 5
```

易错做法是方程两边直接除以 `x`。这一步暗中假设 `x != 0`，会把解 `x=0` 丢掉。因式分解得到的是等价形式；只有在“表达式等于 0”并求出未知数后，才完成了解方程。

### 专题 2：分式方程先写限制再去分母

**例题。** 解 `(x+1)/(x-2)=2`。

```text
限制：x != 2
x + 1 = 2(x - 2)
x + 1 = 2x - 4
x = 5
```

代回原式：左边 `(5+1)/(5-2)=2`，成立，所以 `x=5` 是原方程的解。若计算得到 `x=2`，即使它满足去分母后的式子，也必须舍去。

### 专题 3：用二次函数解释最大值

**例题。** 某活动每天的收益模型为：

```text
y = -2x^2 + 40x - 96
```

其中 `x` 表示每天投入的宣传份数（百份），`y` 表示收益（百元），实际允许 `2 <= x <= 18`。求模型给出的最大收益。

配方：

```text
y = -2(x^2 - 20x) - 96
  = -2(x-10)^2 + 104
```

因为平方项不小于 0，`x=10` 时 `y` 最大，最大值是 104，即投入 1000 份时模型预测收益 10400 元。答案必须同时说明单位和定义域；离开给定范围外推，模型不一定可靠。

### 专题 4：几何证明要写对应关系

**例题。** 在 `△ABC` 中，`AB=AC`，`AD` 平分 `∠BAC` 并交 `BC` 于 `D`。证明 `BD=CD` 且 `AD⊥BC`。

```text
在 △ABD 和 △ACD 中：
AB = AC                 已知
∠BAD = ∠CAD             角平分线定义
AD = AD                 公共边
所以 △ABD ≌ △ACD        SAS
所以 BD = CD，∠ADB = ∠ADC  全等三角形对应部分相等
```

由于 `B、D、C` 共线，`∠ADB+∠ADC=180°`。两个角又相等，所以它们都为 `90°`，从而 `AD⊥BC`。

图上看起来相等或垂直不能作为证明依据；每一步都要能追溯到已知、定义或定理。

### 专题 5：样本方便不等于样本有代表性

学校想了解全校学生每天的睡眠时间。只在早到校的学生中调查，操作方便，但早到校可能与通勤距离、作息习惯有关，样本会偏向某一类学生。

更合理的方案是按年级分层，再从每个年级随机抽取适当人数。报告还要写清样本量、调查日期、问题表述和缺失数据处理。统计图再精美，也不能弥补抽样设计造成的系统偏差。

### 常见易错点

| 易错做法 | 正确诊断 |
| --- | --- |
| `√(a^2)=a` | 应为 `|a|`，因为算术平方根非负 |
| 约分时消掉加法项 | 只能约去分子、分母的公因式 |
| 不等式乘负数不变号 | 乘或除以负数必须改变不等号方向 |
| 只用一组边和一个非夹角判全等 | SSA 通常不能判定全等 |
| 相似比为 `k` 就把面积也乘 `k` | 面积比是 `k^2`，体积比是 `k^3` |
| 相关系数高就断言因果 | 还可能存在混杂因素或共同趋势 |

### 分层练习

**复习巩固。**

1. 因式分解 `2x^2-18`。
2. 解不等式 `3-2x>=7`。
3. 化简 `√27+√12`。

**综合运用。**

4. 解方程 `1/(x-1)=3/(x+1)`，写出取值限制并验根。

综合题：某商店销售一种商品，每件进价 40 元。试销发现售价为 60 元时每天卖 100 件；售价每提高 1 元，每天少卖 2 件。设售价提高 `x` 元。

```text
每天销量 = 100 - 2x
每件利润 = 20 + x
每天利润 y = (20+x)(100-2x)
              = -2x^2 + 60x + 2000
              = -2(x-15)^2 + 2450
```

在合理定义域内，`x=15` 时利润最大，最大利润 2450 元。解答必须说明销量非负、售价与 `x` 的单位，并解释二次函数顶点的现实意义。
