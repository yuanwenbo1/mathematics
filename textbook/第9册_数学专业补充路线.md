# 第 9 册：数学专业补充路线

本册回答一个问题：如果目标是系统学习数学专业，并逐步接近本科高年级甚至研究生方向，还需要学什么？

前面的册次负责启蒙、初等数学、本科前桥梁和应用理解层；本册进入数学专业主线。两者最大的区别不是公式多少，而是思维方式不同：

```text
应用理解层：重点是直观、计算、建模、解释现实问题。
数学专业主线：重点是定义、定理、证明、抽象结构。
```

如果你只是想理解某个应用场景，本册可以选读；如果你想真正补齐数学专业知识，本册就是后续地图。

## 第 1 章：数学专业和工程数学的区别

工程里经常问：

```text
这个公式怎么用？
这个算法怎么跑？
这个模型效果怎么样？
```

数学专业还会继续问：

```text
这个定义为什么这样定？
这个结论在什么条件下成立？
如果条件少一个，还成立吗？
能不能证明？
有没有反例？
```

所以数学专业最重要的训练是：

```text
会读定义
会找条件
会构造例子
会证明
会反驳错误命题
```

## 第 2 章：证明训练

数学专业必须先补证明。

### 2.1 命题

命题是能判断真假的陈述。

例如：

```text
所有偶数都能被 2 整除。  真
存在一个整数 x，使 x^2 = 2。  假
```

### 2.2 量词

常见量词：

```text
∀：对所有
∃：存在
```

例如：

```text
∀x ∈ R, x^2 ≥ 0
```

意思是：对所有实数 `x`，都有 `x^2 ≥ 0`。

### 2.3 常见证明方法

数学专业最常见的证明方法：

```text
直接证明
反证法
逆否命题
数学归纳法
构造法
举反例
```

### 2.4 举反例

很多命题不是证明它真，而是发现它假。

例如命题：

```text
所有函数都是连续的。
```

反例：

```text
f(x)=0, x<0
f(x)=1, x>=0
```

这个函数在 `x=0` 处不连续。

## 第 3 章：集合、关系和映射

集合是数学专业语言的地基。

你需要更熟悉：

```text
集合
子集
并集
交集
差集
笛卡尔积
关系
等价关系
映射
单射
满射
双射
```

工程里说“函数”，数学专业里更常说“映射”。

如果一个映射既是单射又是满射，它就是双射。双射意味着两个集合的元素能一一对应。

## 第 4 章：数学分析

数学分析是数学专业版微积分。

普通微积分更重计算：

```text
怎么求导？
怎么积分？
怎么解题？
```

数学分析更重严谨：

```text
极限到底是什么意思？
连续为什么这样定义？
导数存在需要什么条件？
积分为什么存在？
级数什么时候收敛？
```

核心内容：

```text
实数完备性
数列极限
函数极限
连续性
一致连续
导数
Riemann 积分
无穷级数
函数列和函数项级数
多元函数微分
重积分
曲线积分
曲面积分
```

学习重点不是多算几道题，而是理解这些词：

```text
ε-δ 语言
收敛
一致收敛
完备
紧致
可积
可微
```

## 第 5 章：高等代数

工程线代常关心：

```text

```

高等代数还关心：

```text
向量空间是什么？
线性映射是什么？
基和维数为什么重要？
矩阵只是线性映射的一种表示吗？
```

核心内容：

```text
多项式
行列式
矩阵
线性方程组
向量空间
线性相关和线性无关
基和维数
线性映射
特征值和特征向量
相似矩阵
Jordan 标准形
二次型
内积空间
```

第 2 册学的是工程入口，本章是理论加厚。

## 第 7 章：常微分方程

微分方程研究“函数和它的导数之间的关系”。

例如：

```text
dy/dt = ky
```

意思是：一个量的变化速度和它自己成正比。

核心内容：

```text
一阶微分方程
高阶线性微分方程
常系数线性方程
方程组
稳定性
相图
数值解法
```

应用：

```text
物理运动
控制系统
生态模型
金融模型
神经动力学
```

```text

Lp 空间
```

关键词：

```text
测度
可测
几乎处处

```

实变函数是泛函分析、概率论高级理论、偏微分方程的前置知识。

## 第 16 章：数学专业推荐学习顺序

如果你从当前教材转向数学专业，可以按这个顺序：

```text
证明训练
  -> 集合、逻辑、映射
  -> 数学分析
  -> 高等代数
  -> 解析几何
  -> 常微分方程
  -> 概率论与数理统计
  -> 复变函数
  -> 抽象代数
  -> 实变函数
  -> 拓扑学
  -> 泛函分析
  -> 微分几何
  -> 偏微分方程
  -> 方向专题
```

更现实的三阶段路线：

```text
第一阶段：证明 + 数学分析 + 高等代数
第二阶段：常微分方程 + 概率统计 + 复变函数
第三阶段：实变函数 + 抽象代数 + 拓扑 + 泛函 + 微分几何 + PDE
```

## 第 17 章：方向专题

数学专业后续可以分很多方向：

```text
基础数学：分析、代数、几何、拓扑、数论
应用数学：微分方程、数值分析、优化、控制
计算数学：数值线代、科学计算、计算几何
概率统计：随机过程、统计推断、时间序列
运筹优化：线性规划、凸优化、组合优化
信息与计算：密码学、编码理论、图论、算法数学
AI 理论：优化、概率、信息论、统计学习理论
```

## 第 19 章：本册小结

数学专业路线不是“多学一点公式”，而是换一种训练方式：

```text
从会算，到会证明。
从具体对象，到抽象结构。
从经验正确，到条件严格。
```

如果你只想做工程应用，前 8 册更重要。

如果你想真正靠近数学专业，本册的第一优先级是：

```text
证明训练
数学分析
高等代数
```

这三块打稳后，后面的实变、复变、拓扑、泛函、微分几何才不会像天书。
