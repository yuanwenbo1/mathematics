# 第 5 章：坐标系

### 5.1 坐标

二维坐标写成：

```text
(x, y)
```

例如点 `(3, 2)` 表示：

- 横向走 3。
- 纵向走 2。

平面直角坐标系通常以原点为 `(0, 0)`，向右 `x` 增大，向上 `y` 增大。

### 5.2 两点距离

点 `A(x1, y1)` 和点 `B(x2, y2)` 的距离：

```text
d = √((x2 - x1)^2 + (y2 - y1)^2)
```

例子：

```text
A = (0, 0)
B = (3, 4)
d = √(3^2 + 4^2) = 5
```

![坐标系中两点距离与勾股定理的关系]({{ '/textbook/assets/junior/coordinate-distance.svg' | relative_url }})

*横坐标差、纵坐标差和两点距离构成直角三角形。*

### 5.3 坐标练习

1. 写出点 `A(3, -2)` 到两条坐标轴的距离。
2. 求点 `A(0, 0)` 与点 `B(6, 8)` 的距离。
3. 点 `P(a, b)` 关于 `x` 轴、`y` 轴和原点的对称点分别是什么？

答案：`2, 3`；`10`；`(a, -b)`、`(-a, b)`、`(-a, -b)`。
