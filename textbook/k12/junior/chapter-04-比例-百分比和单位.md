# 第 4 章：比例、百分比和单位

### 4.1 比例

比例描述“两个量之间的倍数关系”。

```text
a:b = 2:3
```

表示 `a` 和 `b` 的比例是 2 比 3。

如果总量是 50，按 2:3 分：

```text
总份数 = 2 + 3 = 5
a = 50 * 2/5 = 20
b = 50 * 3/5 = 30
```

### 4.2 增长率

```text
增长率 = (新值 - 旧值) / 旧值
```

例子：

```text
旧值 = 100
新值 = 120
增长率 = (120 - 100) / 100 = 20%
```

### 4.3 折扣

```text
八折 = 原价 * 0.8
七五折 = 原价 * 0.75
```

### 4.4 单位换算

存储容量常用二进制单位：

```text
1 KB = 1024 B
1 MB = 1024 KB
```

速度中常见：

```text
1 m/s = 3.6 km/h
```

### 4.5 本章练习

1. 80 按 3:5 分，两个数分别是多少？
2. 从 200 增长到 250，增长率是多少？
3. 100 元打 75 折是多少钱？
4. 2 MB 等于多少 KB？

答案：

```text
1. 30 和 50
2. 25%
3. 75 元
4. 2048 KB
```
