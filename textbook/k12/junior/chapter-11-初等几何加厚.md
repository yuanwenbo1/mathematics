# 第 11 章：初等几何加厚

### 11.1 角

角可以理解为两条线张开的大小。

常见角：

```text
锐角：小于 90°
直角：等于 90°
钝角：大于 90° 小于 180°
平角：180°
周角：360°
```

生活例子：

```text
书本的角通常是直角。
钟表 3 点整时，时针和分针成直角。
```

### 11.2 平行和垂直

平行：

```text
两条线一直不相交。
```

垂直：

```text
两条线相交成直角。
```

生活例子：

```text
作业本上的横线通常互相平行。
桌面边和桌腿大致垂直。
```

### 11.3 三角形

三角形有三条边、三个角。

常见三角形：

```text
等边三角形：三条边一样长。
等腰三角形：有两条边一样长。
直角三角形：有一个角是 90°。
```

直角三角形以后会连接到勾股定理：

```text
a^2 + b^2 = c^2
```

### 11.4 四边形

常见四边形：

```text
正方形
长方形
平行四边形
梯形
菱形
```

先观察：

```text
有没有平行边？
有没有直角？
边是否一样长？
```

### 11.5 圆

圆的核心词：

```text
圆心
半径
直径
周长
面积
```

关系：

```text
直径 = 2 * 半径
```

圆周率：

```text
π ≈ 3.14
```

小学阶段先知道它是一个固定比例，不必急着证明。
