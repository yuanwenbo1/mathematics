# 第 18 章：图形性质与几何证明

### 18.1 命题、定义与证明

命题由条件和结论组成。真命题需要证明，说明假命题只需一个反例。证明时不能把要证明的结论当作已知条件。

标准书写：

```text
已知：明确条件
求证：明确结论
证明：每一步写依据
```

### 18.2 相交线、平行线与角

对顶角相等，邻补角和为 180°。平行线的判定与性质要区分：

- 同位角相等、内错角相等或同旁内角互补，可以判定两直线平行。
- 两直线平行，可以推出同位角相等、内错角相等、同旁内角互补。

### 18.3 三角形与全等

三角形内角和为 180°，外角等于与它不相邻的两个内角之和。全等三角形的对应边、对应角相等，常用判定：SSS、SAS、ASA、AAS，以及直角三角形的 HL。

例：在 `△ABC` 与 `△DEF` 中，若 `AB=DE, AC=DF, ∠A=∠D`，则由 SAS 可证两三角形全等。必须保证这个角是两组已知边的夹角。

*图上的刻痕表示对应边相等，角弧表示夹角相等；证明时还要把这些条件写出来。*

### 18.4 等腰三角形、勾股定理

等腰三角形两底角相等；反过来，有两个角相等的三角形是等腰三角形。直角三角形两直角边为 `a,b`，斜边为 `c`：

```text
a^2 + b^2 = c^2
```

逆定理也成立，可用三边关系判断直角三角形。勾股定理只适用于直角三角形。

### 18.5 相似三角形

相似图形形状相同、大小可以不同。三角形相似的常用判定：AA、两边成比例且夹角相等、三边成比例。

相似比为 `k` 时：周长比为 `k`，面积比为 `k^2`。利用同一时刻物体与影子的相似三角形，可以间接测高。

### 18.6 四边形

```text
平行四边形：两组对边分别平行
矩形：有一个角是直角的平行四边形
菱形：有一组邻边相等的平行四边形
正方形：既是矩形又是菱形
```

平行四边形的对边相等、对角相等、对角线互相平分。矩形对角线相等，菱形对角线互相垂直，正方形同时具有这些特殊性质。

### 18.7 圆

圆中常见对象包括弦、弧、圆心角、圆周角、切线。核心结论：

- 同弧所对的圆周角相等，圆周角等于同弧圆心角的一半。
- 直径所对的圆周角是直角。
- 切线垂直于经过切点的半径。
- 从圆外一点引圆的两条切线，切线长相等。

弧长与扇形面积：

```text
弧长 = n/360 * 2πr
扇形面积 = n/360 * πr^2
```

### 18.8 尺规作图与证明验收

应会用无刻度直尺和圆规完成：作线段等长、作角等大、作角平分线、作线段垂直平分线、过一点作已知直线的垂线。作图后要说明依据。

证明题：在平行四边形 `ABCD` 中，对角线交于 `O`。证明 `OA=OC` 且 `OB=OD`。

思路：由 `AB // CD` 得一组内错角相等，再用平行四边形对边相等证明两三角形全等，得到对应边相等。
