# 第 1 章：数和运算

> **本章核心：** 先确定数的范围和符号，再按“括号、乘方、乘除、加减”计算；分母不能为 0，偶次根号内的数不能为负。
>
> **最小例题：** `2 + 3 * 4 = 14`，而 `(2 + 3) * 4 = 20`。括号改变运算顺序，也会改变结果。
>
> **过关标准：** 能完成含负数、分数、乘方和根号的运算，并说明每一步依据。

### 1.1 常见的数

数学里最基础的对象是数。

| 类型 | 例子 | 用途 |
|---|---|---|
| 自然数 | 0, 1, 2, 3 | 计数 |
| 整数 | -2, -1, 0, 1 | 表示正负变化 |
| 小数 | 0.5, 3.14 | 表示连续数量 |
| 分数 | 1/2, 3/4 | 表示比例 |
| 百分数 | 20% | 表示每 100 份中有多少份 |

### 1.2 运算顺序

一般顺序：

```text
括号 > 幂运算 > 乘除 > 加减
```

例子：

```text
2 + 3 * 4 = 14
(2 + 3) * 4 = 20
```

### 1.3 正数和负数

正数可以理解为增加、向右、向上、盈利。

负数可以理解为减少、向左、向下、亏损。

例如：

```text
+100 表示收入 100
-50 表示支出 50
```

数轴和温度也用正负表示相反方向：

```text
0 的右边是正数，左边是负数。
零上 5 摄氏度记作 +5℃，零下 5 摄氏度记作 -5℃。
```

### 1.4 分数、小数、百分数

```text
1/2 = 0.5
1/4 = 0.25
3/4 = 0.75
50% = 0.5
20% = 0.2
```

例如一次测验共 100 题，答对 85 题：

```text
正确率 = 答对题数 / 总题数
85 / 100 = 85%
```

### 1.5 幂运算

幂运算是重复相乘：

```text
2^3 = 2 * 2 * 2 = 8
10^3 = 1000
```

平方表示一个数乘自身：

```text
(-3)^2 = (-3) * (-3) = 9
```

注意 `-3^2 = -(3^2) = -9`，而 `(-3)^2 = 9`。括号决定负号是否参与乘方。

### 1.6 根号

根号和平方相反：

```text
√9 = 3
√16 = 4
```

注意：`√` 默认表示算术平方根，也就是非负的那个结果。

所以：

```text
√49 = 7
```

但如果题目写的是：

```text
x^2 = 49
```

那么解是：

```text
x = 7 或 x = -7
```

也可以写成：

```text
x = ±7
```

区别：

```text
√49 是一个数，默认取非负结果。
x^2 = 49 是一个方程，要找所有平方后等于 49 的 x。
```

勾股定理中，两条直角边为 6 和 8 时，斜边为：

```text
√(6^2 + 8^2) = √100 = 10
```

长度不能为负，所以取算术平方根。

### 1.7 本章练习

1. `3 + 4 * 5`
2. `(3 + 4) * 5`
3. `35%` 写成小数。
4. `2^5`
5. `√49`
6. 方程 `x^2 = 49` 的解是什么？
7. 直角三角形两条直角边为 6 和 8，求斜边长。

答案：

```text
1. 23
2. 35
3. 0.35
4. 32
5. 7
6. x = ±7
7. 10
```
