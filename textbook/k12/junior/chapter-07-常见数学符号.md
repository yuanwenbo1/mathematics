# 第 7 章：常见数学符号

### 7.1 等号和约等号

```text
=    等于
≈    约等于
≠    不等于
```

### 7.2 大小关系

```text
>    大于
<    小于
>=   大于等于
<=   小于等于
```

### 7.3 求和符号

```text
Σ
```

表示把很多项加起来。

例如：

```text
Σ xi = x1 + x2 + x3 + ... + xn
```

### 7.4 下标

```text
x1, x2, x3
```

表示一组数里的第 1 个、第 2 个、第 3 个。

在数据中：

```text
x_i 表示第 i 个样本
```
