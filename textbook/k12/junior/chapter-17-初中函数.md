# 第 17 章：初中函数

### 17.1 函数的三种表示

在一个变化过程中，如果给定 `x` 的一个允许取值，都有唯一的 `y` 与它对应，那么 `y` 是 `x` 的函数。函数可用列表、解析式和图像表示。

研究函数统一回答四个问题：定义域是什么、变量怎样对应、图像怎样变化、模型适合解决什么问题。

### 17.2 正比例和一次函数

```text
正比例函数：y = kx  （k != 0）
一次函数：y = kx + b  （k != 0）
```

`k` 决定增减和倾斜程度，`b` 是 `y` 轴截距。两点确定一条直线，斜率为 `(y2-y1)/(x2-x1)`（`x1 != x2`）。

一次函数可以解决固定费用加单位费用的问题。例如打车费 `y = 10 + 2.4x`，其中 10 是起步固定费用，2.4 是每千米增加费用。

### 17.3 反比例函数

```text
y = k/x  （k != 0，x != 0）
```

图像是双曲线。`k > 0` 时两支在第一、三象限；`k < 0` 时在第二、四象限。矩形面积固定时，长和宽构成反比例关系。

### 17.4 二次函数

```text
y = ax^2 + bx + c  （a != 0）
```

图像是抛物线，对称轴 `x = -b/(2a)`，顶点横坐标是 `-b/(2a)`。配方得到：

```text
y = a(x-h)^2 + k
```

顶点为 `(h,k)`。二次函数与一元二次方程相连：方程的实根就是抛物线与 `x` 轴交点的横坐标。

例：`y=-x^2+6x-5=-(x-3)^2+4`，最大值为 4，在 `x=3` 处取得。

### 17.5 函数建模步骤

```text
确定变量与单位
分析对应关系
选择函数类型
求参数
检查定义域和图像
解释结果及模型限制
```

不要把相关关系自动当成因果关系，也不要在样本范围之外随意外推。

### 17.6 本章验收

1. 直线经过 `(1,3)` 和 `(4,9)`，求解析式。
2. `y=-2x^2+8x-3` 的对称轴是什么？
3. 同样路程下，速度和时间是什么比例关系？说明条件。

答案：`y=2x+1`；`x=2`；路程固定且速度、时间为正时成反比例。
