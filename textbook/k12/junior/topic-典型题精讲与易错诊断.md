# 初中专题：典型题精讲与易错诊断

本专题把代数、函数、几何和统计放到同一套解题流程中：先确认条件和定义域，再选择方法，最后用代入、图像、数量级或逻辑关系检查。

### 专题 1：因式分解不是解方程

**例题。** 解方程 `x^2-5x=0`。

先因式分解：

```text
x^2 - 5x = x(x-5)
x(x-5) = 0
```

两个因式的积为 0，所以至少有一个因式为 0：

```text
x = 0 或 x - 5 = 0
x = 0 或 x = 5
```

易错做法是方程两边直接除以 `x`。这一步暗中假设 `x != 0`，会把解 `x=0` 丢掉。因式分解得到的是等价形式；只有在“表达式等于 0”并求出未知数后，才完成了解方程。

### 专题 2：分式方程先写限制再去分母

**例题。** 解 `(x+1)/(x-2)=2`。

```text
限制：x != 2
x + 1 = 2(x - 2)
x + 1 = 2x - 4
x = 5
```

代回原式：左边 `(5+1)/(5-2)=2`，成立，所以 `x=5` 是原方程的解。若计算得到 `x=2`，即使它满足去分母后的式子，也必须舍去。

### 专题 3：用二次函数解释最大值

**例题。** 某活动每天的收益模型为：

```text
y = -2x^2 + 40x - 96
```

其中 `x` 表示每天投入的宣传份数（百份），`y` 表示收益（百元），实际允许 `2 <= x <= 18`。求模型给出的最大收益。

配方：

```text
y = -2(x^2 - 20x) - 96
  = -2(x-10)^2 + 104
```

因为平方项不小于 0，`x=10` 时 `y` 最大，最大值是 104，即投入 1000 份时模型预测收益 10400 元。答案必须同时说明单位和定义域；离开给定范围外推，模型不一定可靠。

### 专题 4：几何证明要写对应关系

**例题。** 在 `△ABC` 中，`AB=AC`，`AD` 平分 `∠BAC` 并交 `BC` 于 `D`。证明 `BD=CD` 且 `AD⊥BC`。

```text
在 △ABD 和 △ACD 中：
AB = AC                 已知
∠BAD = ∠CAD             角平分线定义
AD = AD                 公共边
所以 △ABD ≌ △ACD        SAS
所以 BD = CD，∠ADB = ∠ADC  全等三角形对应部分相等
```

由于 `B、D、C` 共线，`∠ADB+∠ADC=180°`。两个角又相等，所以它们都为 `90°`，从而 `AD⊥BC`。

图上看起来相等或垂直不能作为证明依据；每一步都要能追溯到已知、定义或定理。

### 专题 5：样本方便不等于样本有代表性

学校想了解全校学生每天的睡眠时间。只在早到校的学生中调查，操作方便，但早到校可能与通勤距离、作息习惯有关，样本会偏向某一类学生。

更合理的方案是按年级分层，再从每个年级随机抽取适当人数。报告还要写清样本量、调查日期、问题表述和缺失数据处理。统计图再精美，也不能弥补抽样设计造成的系统偏差。

### 常见易错点

| 易错做法 | 正确诊断 |
| --- | --- |
| `√(a^2)=a` | 应为 `|a|`，因为算术平方根非负 |
| 约分时消掉加法项 | 只能约去分子、分母的公因式 |
| 不等式乘负数不变号 | 乘或除以负数必须改变不等号方向 |
| 只用一组边和一个非夹角判全等 | SSA 通常不能判定全等 |
| 相似比为 `k` 就把面积也乘 `k` | 面积比是 `k^2`，体积比是 `k^3` |
| 相关系数高就断言因果 | 还可能存在混杂因素或共同趋势 |

### 分层练习

**复习巩固。**

1. 因式分解 `2x^2-18`。
2. 解不等式 `3-2x>=7`。
3. 化简 `√27+√12`。

**综合运用。**

4. 解方程 `1/(x-1)=3/(x+1)`，写出取值限制并验根。
5. 抛物线 `y=x^2-6x+5` 的对称轴、顶点和与 `x` 轴交点分别是什么？
6. 等腰三角形的两边长为 5 和 12，求周长，并说明为什么只有一种答案。

**拓广探索。**

7. 一次函数经过 `(0,8)`、`(4,20)`。写出解析式，并解释斜率和截距在“固定费用加按量收费”模型中的含义。
8. 圆 `O` 的半径为 5，点 `P` 到圆心距离为 13。从 `P` 引切线 `PA`，求 `PA`。
9. 设计一项了解本年级课外阅读时间的抽样调查，写出总体、样本、抽样方法和一个可能的误差来源。

### 练习答案与提示

1. `2(x-3)(x+3)`。
2. `-2x>=4`，所以 `x<=-2`。
3. `3√3+2√3=5√3`。
4. 限制 `x!=1,-1`；去分母得 `x+1=3x-3`，所以 `x=2`，代回成立。
5. `y=(x-3)^2-4`，对称轴 `x=3`，顶点 `(3,-4)`，交点 `(1,0)`、`(5,0)`。
6. 周长 29。若两腰为 5，则 `5+5<12`，不能构成三角形；只能以 12 为腰、5 为底。
7. `y=3x+8`；3 表示每增加一个计费单位增加 3 元，8 表示用量为 0 时仍有 8 元固定费用。
8. 半径垂直切线，`PA=√(13^2-5^2)=12`。
9. 示例：总体是全年级学生；按班级分层随机抽取学生；误差可能来自回忆不准确、未回复或问题表述含糊。
