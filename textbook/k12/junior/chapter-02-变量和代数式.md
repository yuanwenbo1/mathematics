# 第 2 章：变量和代数式

### 2.1 变量

变量就是可以变化的数。

例如，用字母表示单价、数量和总价：

```text
用 p 表示单价
用 n 表示数量
用 T 表示总价
```

那么：

```text
T = pn
```

### 2.2 代数式

含有变量的式子叫代数式：

```text
2x + 3
x^2 + 1
3a + 2b
```

代数式不是一个固定数字，而是一套计算规则。

当 `x = 4`：

```text
2x + 3 = 2 * 4 + 3 = 11
```

### 2.3 同类项合并

```text
2x + 3x = 5x
4a + 2b + 3a = 7a + 2b
```

不同变量不能随便合并：

```text
2x + 3y
```

### 2.4 本章练习

1. 当 `x = 3`，`2x + 5` 等于多少？
2. 当 `x = 4`，`x^2 + 1` 等于多少？
3. 化简 `3a + 2a`。
4. 化简 `4x + 3y + 2x`。
5. 如果 `y = 2x + 1`，当 `x = 10`，`y` 是多少？

答案：

```text
1. 11
2. 17
3. 5a
4. 6x + 3y
5. 21
```
