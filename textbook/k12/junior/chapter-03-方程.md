# 第 3 章：方程

### 3.1 方程是什么

方程就是含有未知数的等式。

```text
x + 3 = 10
```

意思是：什么数加 3 等于 10？

答案：

```text
x = 7
```

### 3.2 解方程的核心

等式两边做同样的操作，等式仍然成立。

```text
x + 3 = 10
x = 10 - 3
x = 7
```

再看：

```text
2x = 12
x = 12 / 2
x = 6
```

![方程天平示意图：等式两边同时减三]({{ '/textbook/assets/junior/equation-balance.svg' | relative_url }})

*移项不是数字“换边变号”，本质是等式两边同时做相同操作。*

### 3.3 为什么要列方程

方程把题目中的等量关系写成数学式：

```text
已知一些条件，求未知量。
```

例如“一个数的 2 倍加 3 等于 11”，设这个数为 `x`，等量关系就是 `2x + 3 = 11`。

### 3.4 一元一次方程

形式：

```text
ax + b = c
```

例子：

```text
3x + 2 = 14
3x = 12
x = 4
```

### 3.5 本章练习

1. `x + 5 = 12`
2. `2x = 18`
3. `3x + 2 = 14`
4. `x / 4 = 6`
5. `5x - 3 = 22`

答案：

```text
1. x = 7
2. x = 9
3. x = 4
4. x = 24
5. x = 5
```
