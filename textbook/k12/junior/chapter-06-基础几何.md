# 第 6 章：基础几何

### 6.1 点、线、面

- 点：位置。
- 线：点运动形成的轨迹。
- 面：二维区域。

### 6.2 面积

矩形面积：

```text
S = 长 * 宽
```

圆面积：

```text
S = πr^2
```

### 6.3 角度和弧度

角度：

```text
90° 是直角
180° 是平角
360° 是一圈
```

弧度：

```text
180° = π 弧度
360° = 2π 弧度
```

角度转弧度用 `弧度 = 角度 * π / 180`，弧度转角度用 `角度 = 弧度 * 180 / π`。
