# 第 15 章：小学五至六年级的数与代数

### 15.1 因数、倍数与整数性质

在非零自然数范围内研究因数和倍数。最大公因数可用于约分，最小公倍数可用于通分。分解质因数能系统地找到它们。

```text
12 = 2^2 * 3
18 = 2 * 3^2
最大公因数 = 2 * 3 = 6
最小公倍数 = 2^2 * 3^2 = 36
```

### 15.2 分数四则运算

异分母分数加减先通分：

```text
1/3 + 1/4 = 4/12 + 3/12 = 7/12
```

分数乘法把“一个量的几分之几”继续缩放：

```text
2/3 * 3/5 = 6/15 = 2/5
```

除以一个非零分数，等于乘它的倒数：

```text
3/4 / 2/5 = 3/4 * 5/2 = 15/8
```

每次计算后都要检查：结果应大于还是小于原数？单位是否一致？能否约分？

### 15.3 小数四则运算

小数乘法先按整数相乘，再根据两个因数一共有几位小数确定积的小数位。小数除法可以把除数和被除数同时扩大相同倍数，把除数变成整数。

```text
2.4 * 0.35 = 0.84
7.2 / 0.6 = 72 / 6 = 12
```

### 15.4 百分数、折扣与利率

百分数表示“每一百份中有多少份”，不能单独带具体单位。

```text
合格率 = 合格数量 / 总数量 * 100%
现价 = 原价 * 折扣率
简单利息 = 本金 * 年利率 * 年数
```

例：原价 240 元，打八五折，现价是 `240 * 85% = 204` 元。

### 15.5 比、比例与正反比例

比 `a:b` 描述两个量的倍数关系。比例 `a:b = c:d` 表示两个比相等，且在分母不为 0 时有 `ad = bc`。

- 正比例：`y/x = k`，图像是经过原点的直线。
- 反比例：`xy = k`，一个量扩大，另一个量按相同比例缩小。

判断比例关系不能只看“一起变大或变小”，必须检查比值或乘积是否保持不变。

### 15.6 用字母表示数与简易方程

字母可以表示未知数，也可以表示会变化的量或一般规律。`a * 1 = a` 比列举许多个例子更一般。

解简易方程要保持等式两边相等：

```text
3x + 5 = 20
3x = 15
x = 5
```

### 15.7 负数初步

负数用于表示与规定正方向相反的量，例如零下温度、低于海平面、支出。数轴上右边的数总比左边大，因此 `-2 > -5`。
