# 第 5 章：比例和比率

### 5.1 比例

比例描述两个量之间的关系。

例如：

```text
男生:女生 = 2:3
```

如果总人数 50：

```text
男生 = 50 * 2/(2+3) = 20
女生 = 50 * 3/(2+3) = 30
```

![按二比三分配五十的条带图]({{ '/textbook/assets/primary/ratio-bars.svg' | relative_url }})

*先把总量看成 `2 + 3 = 5` 份，再求每份是多少。*

### 5.2 比率

比率是一个量除以另一个量。

```text
转化率 = 成交人数 / 访问人数
```

例如 100 人访问，5 人购买：

```text
转化率 = 5 / 100 = 5%
```
