# 第 14 章：小学三至四年级完整课程

### 14.1 大数、估算与计算策略

认识万以上的自然数时，可以用数级分组：个级、万级、亿级。`120305006` 读作“一亿二千零三十万五千零六”。估算不是随意取数，而是根据问题选择合理的近似精度。

例：每箱 198 本书，8 箱大约有多少本？把 198 看成 200，得到 `200 * 8 = 1600` 本。精确值是 1584，估算可以用来检查数量级。

### 14.2 多位数乘除法

竖式乘法把乘数每一位产生的部分积按数位对齐后相加。竖式除法每一步都在回答“当前部分最多包含几个除数”。

检验方法：

```text
乘法：积 / 一个因数 = 另一个因数
除法：商 * 除数 + 余数 = 被除数
余数必须小于除数
```

### 14.3 小数和分数初步

`0.1` 是十分之一，`0.01` 是百分之一。小数加减时应对齐小数点，本质是让相同计数单位对齐。

分数 `a/b` 中，`b` 表示把单位“1”平均分成多少份，`a` 表示取了多少份。分母相同才能直接合并分子，因为所取的每一份大小相同。

### 14.4 面积与角

面积描述平面的大小，必须用平方单位。长方形面积 `S = 长 * 宽`，正方形面积 `S = 边长^2`。角的大小与两条边画得多长无关，只与张开的程度有关。

常见角：锐角小于 90°，直角等于 90°，钝角大于 90°且小于 180°，平角等于 180°，周角等于 360°。

### 14.5 平移、旋转、轴对称

- 平移改变位置，不改变形状、大小和方向。
- 旋转围绕一个点转过一定角度。
- 轴对称图形沿对称轴折叠后两侧重合。

在方格纸上描述变换时，要说清方向和格数，旋转还要说清中心、方向和角度。

### 14.6 条形图与平均数

条形图适合比较不同类别的数量。平均数 `总数 / 份数` 表示一组数据的平均水平，但它不一定是数据中实际出现过的数，也可能被极端值影响。

### 14.7 中年级验收

1. 计算 `408 * 25`，再用估算检查。
2. 计算 `725 / 6`，写出商和余数，并验算。
3. `3.70` 和 `3.7` 是否相等？为什么？
4. 长 12 米、宽 8 米的长方形草地面积是多少？
5. 画出一个有两条对称轴的图形。

答案：`10200`；商 120 余 5；相等，末尾的 0 不改变计数值；`96 平方米`；例如长方形（非正方形）。
