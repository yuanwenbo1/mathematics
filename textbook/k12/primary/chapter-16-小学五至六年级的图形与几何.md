# 第 16 章：小学五至六年级的图形与几何

### 16.1 三角形和多边形

三角形内角和是 180°。任意两边之和大于第三边。平行四边形面积 `底 * 高`，三角形面积 `底 * 高 / 2`，梯形面积 `(上底 + 下底) * 高 / 2`。

这些公式都可以通过剪拼转化为长方形或平行四边形来理解，不应只背结果。

### 16.2 圆

圆的周长和面积：

```text
C = 2πr = πd
S = πr^2
```

半径扩大 2 倍，周长扩大 2 倍，面积扩大 4 倍。扇形可以理解为圆的一部分，圆心角占 360° 的比例就是扇形占整圆的比例。

### 16.3 长方体、正方体、圆柱与圆锥

```text
长方体体积 = 长 * 宽 * 高
正方体体积 = 棱长^3
圆柱体积 = 底面积 * 高
圆锥体积 = 底面积 * 高 / 3
```

表面积计算的是所有外表面的面积，体积计算的是物体占据空间的大小，容积计算的是容器内部能装多少。三者不能混用。

### 16.4 比例尺、位置与变换

比例尺是图上距离与实际距离的比。使用比例尺时必须统一单位。用数对 `(列, 行)` 或方向加距离可以确定位置；放大、缩小、平移、旋转和轴对称都要描述对应点的变化。
