# 儿童扩展 3：乘法口诀不是死背

### 3.1 乘法是重复加法

```text
3 * 4
```

可以理解为：

```text
3 + 3 + 3 + 3 = 12
```

也可以理解为：

```text
4 组，每组 3 个
```

### 3.2 用方阵理解乘法

```text
● ● ●
● ● ●
● ● ●
● ● ●
```

这是 `4 行，每行 3 个`，所以：

```text
4 * 3 = 12
```

换个方向看，也是：

```text
3 * 4 = 12
```

这能帮助孩子理解：

```text
3 * 4 = 4 * 3
```

### 3.3 口诀练习

不要一次背完整张表。可以这样分：

```text
先背 2、5、10
再背 3、4
最后背 6、7、8、9
```

练习：

1. `2 * 7`
2. `5 * 6`
3. `3 * 8`
4. `4 * 9`
5. `6 * 7`

答案：

```text
1. 14
2. 30
3. 24
4. 36
5. 42
```
