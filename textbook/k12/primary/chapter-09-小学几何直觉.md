# 第 9 章：小学几何直觉

### 9.1 长度、面积、体积

长度是一维。

面积是二维。

体积是三维。

```text
矩形面积 = 长 * 宽
长方体体积 = 长 * 宽 * 高
```

![长度、面积和体积的维度区别]({{ '/textbook/assets/primary/measure-dimensions.svg' | relative_url }})

*长度、面积、体积对应一维、二维、三维，单位分别带一次方、平方和立方。*

### 9.2 周长

周长是边界长度。

```text
矩形周长 = 2 * (长 + 宽)
```

### 9.3 图像中的几何

图像目标框：

```text
面积 = 宽 * 高
```

目标检测中经常计算框的重叠程度，后面会学 IoU。
