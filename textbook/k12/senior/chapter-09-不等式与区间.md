# 第 9 章：不等式与区间

### 9.1 基本不等式

```text
x > 3
x <= 10
```

表示范围。

### 9.2 区间

```text
0 <= x <= 1
```

表示 `x` 在 0 和 1 之间。

概率常常在这个区间：

```text
0 <= p <= 1
```

### 9.3 解不等式的规则

不等式两边同时加上或减去同一个数，不等号方向不变：

```text
x - 3 > 2
x > 5
```

两边同时乘或除以负数时，不等号必须反向：

```text
-2x < 6
x > -3
```
