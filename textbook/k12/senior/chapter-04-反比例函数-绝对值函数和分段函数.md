# 第 4 章：反比例函数、绝对值函数和分段函数

这一章只比较三类函数的定义域、解析式和图像特征。

### 4.1 反比例函数

反比例函数常见形式：

```text
y = k / x
```

其中 `x ≠ 0`。

例如：

```text
y = 1 / x
```

当 `x` 越接近 0，函数值变化越剧烈。

它的定义域和值域都不含 0；当 `k > 0` 时，图像位于第一、第三象限。

### 4.2 绝对值函数

绝对值表示一个数到 0 的距离。

```text
|3| = 3
|-3| = 3
```

绝对值函数：

```text
y = |x|
```

它的图像像一个 V。

绝对值也可以写成分段形式：

```text
|x| = x,  x >= 0
|x| = -x, x < 0
```

### 4.3 分段函数

分段函数是“不同范围用不同规则”的函数。

例如阶梯收费：

```text
f(x) = 5,          0 < x <= 2
f(x) = 5 + 2(x-2), x > 2
```

写分段函数时，先划分自变量范围，再分别写规则，并检查分界点属于哪一段。
