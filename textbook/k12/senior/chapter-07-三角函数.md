# 第 7 章：三角函数

### 7.1 角度和弧度

角度与弧度的对应关系：

```text
180° = π
90° = π/2
360° = 2π
```

### 7.2 sin、cos、tan

在直角三角形中：

```text
sin = 对边 / 斜边
cos = 邻边 / 斜边
tan = 对边 / 邻边
```

注意：`tan` 要求邻边不为 0。换成角度语言，`90°`、`270°` 这类位置的 `tan` 在实数里没有定义。

在单位圆上：

```text
cosθ 是点的横坐标。
sinθ 是点的纵坐标。
```

### 7.3 单位圆与基本关系

单位圆上点 `P(cosθ, sinθ)` 到原点的距离为 1，因此：

```text
sin^2θ + cos^2θ = 1
```

只要 `cosθ ≠ 0`，还有 `tanθ = sinθ / cosθ`。这两个关系是三角恒等变形的起点。
