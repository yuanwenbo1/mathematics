# 第 12 章：相等、不等与二次关系

### 12.1 等式与不等式性质

不等式两边同时加同一个数，方向不变；同乘正数，方向不变；同乘负数，方向改变。比较大小常用作差法：研究 `a-b` 的符号。

### 12.2 基本不等式

当 `a,b >= 0` 时：

```text
√(ab) <= (a+b)/2
```

等号当且仅当 `a=b`。使用基本不等式求最值前必须检查“一正、二定、三相等”：变量为正，和或积固定，等号条件可取得。

例：正数 `x,y` 满足 `x+y=10`，则 `xy <= 25`，当 `x=y=5` 时取等号。

### 12.3 一元二次不等式

解 `ax^2+bx+c > 0` 时，把二次函数图像、方程根和不等式符号统一起来。

例：

```text
x^2 - 5x + 6 > 0
(x-2)(x-3) > 0
x < 2 或 x > 3
```

若二次项系数为正，图像开口向上，在两个实根外侧为正、内侧为负。没有实根时要结合开口方向判断恒正或恒负。
