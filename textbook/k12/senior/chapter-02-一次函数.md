# 第 2 章：一次函数

### 2.1 形式

一次函数：

```text
y = kx + b
```

- `k` 是斜率。
- `b` 是截距。

`k` 决定倾斜程度，`b` 决定整体上下移动。

下面这个动态图展示的是：`b = 1` 不变，`k` 从负数变到正数时，直线如何旋转。

![一次函数斜率变化动态图]({{ '/textbook/assets/functions/linear-slope.gif' | relative_url }})

### 2.2 斜率

斜率表示 `x` 增加 1 时，`y` 改变多少。

```text
y = 2x + 1
```

`x` 每增加 1，`y` 增加 2。

如果：

```text
y = -3x + 1
```

`x` 每增加 1，`y` 减少 3。

### 2.3 截距

截距 `b` 表示当 `x = 0` 时，直线和 y 轴相交的位置。

例如：

```text
y = 2x + 1
```

当 `x = 0`：

```text
y = 1
```

所以截距是 1。

### 2.4 线性模型

一次函数可以描述固定变化率：

```text
y = kx + b
```

其中 `k` 是每增加 1 个单位时的变化量，`b` 是初始值。

### 2.5 练习

1. `y = 3x + 2`，当 `x = 4`，`y` 是多少？
2. `y = -x + 5` 的斜率是多少？
3. `y = 2x - 3` 的截距是多少？
4. 如果一条直线斜率为正，它大致向哪个方向倾斜？

答案：

```text
1. 14
2. -1
3. -3
4. 从左下到右上。
```
