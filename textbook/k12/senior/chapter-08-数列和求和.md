# 第 8 章：数列和求和

### 8.1 数列

数列是一串有顺序的数：

```text
1, 2, 3, 4, 5
```

### 8.2 等差数列

相邻两项差相同：

```text
2, 5, 8, 11
```

差是 3。

### 8.3 等比数列

相邻两项倍数相同：

```text
2, 4, 8, 16
```

公比是 2。

### 8.4 求和符号

```text
Σ xi
```

表示把所有 `xi` 加起来。

前 `n` 项和是：

```text
S_n = x_1 + x_2 + ... + x_n
```

等差数列前 `n` 项和为 `S_n = n(a_1 + a_n)/2`；等比数列在 `q ≠ 1` 时，`S_n = a_1(1-q^n)/(1-q)`。
