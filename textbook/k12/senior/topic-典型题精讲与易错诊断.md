# 高中专题：典型题精讲与易错诊断

高中综合题往往不是公式更多，而是需要在函数、代数、几何、概率和现实约束之间切换。本专题示范完整推理链，不把关键步骤省略成“显然”。

### 专题 1：函数零点与二分法

**例题。** 说明 `f(x)=x^3-x-1` 在区间 `(1,2)` 内有零点，并用二分法把零点缩小到长度不超过 `0.05` 的区间。

多项式函数连续，且：

```text
f(1) = -1 < 0
f(2) = 5 > 0
```

由零点存在定理，`(1,2)` 内至少有一个零点。继续取中点：

```text
f(1.5) = 0.875 > 0       零点在 (1,1.5)
f(1.25) = -0.296875 < 0  零点在 (1.25,1.5)
f(1.375) > 0             零点在 (1.25,1.375)
f(1.3125) < 0            零点在 (1.3125,1.375)
f(1.34375) > 0           零点在 (1.3125,1.34375)
```

最后区间长度是 `0.03125<0.05`。二分法给的是逐步缩小的可靠区间；仅看到图像穿过坐标轴，不足以代替连续性与符号变化的说明。

### 专题 2：从三角函数读出周期模型

**例题。** 某周期量用

```text
h(t) = 3sin[π/6 * (t-3)] + 5
```

描述，其中 `t` 以小时计。解释各参数，并求一个周期内第一次达到最大值的时刻。

- 振幅为 3，表示相对中心值最多上下变化 3。
- 中心值为 5，所以值域是 `[2,8]`。
- 角速度为 `π/6`，周期 `T=2π/(π/6)=12` 小时。
- `t-3` 表示相对基本正弦曲线向右平移 3 小时。

正弦在相位等于 `π/2` 时第一次取最大值：

```text
π/6 * (t-3) = π/2
t-3 = 3
t = 6
```

模型给出的第一次峰值时刻是 6 小时。实际使用时还要说明 `t=0` 对应什么时刻，以及模型在哪个时间范围内有效。

### 专题 3：等比数列与复利

本金 10000 元按年利率 2% 计复利，不考虑存取和税费。第 `n` 年末本息为：

```text
a_n = 10000 * 1.02^n
```

第三年末：

```text
a_3 = 10000 * 1.02^3 = 10612.08 元
```

这里每过一年都把上一年末的金额乘 1.02，所以是等比变化。若每年还固定追加存款，就不再只是一个简单等比数列，需要把每笔存款分别累积后求和。

### 专题 4：解析几何要同时看方程和图形

**例题。** 直线 `y=3` 与圆 `x^2+y^2=25` 相交于 `A、B`，求弦长 `AB`。

代入 `y=3`：

```text
x^2 + 9 = 25
x^2 = 16
x = ±4
```

所以交点是 `(-4,3)` 和 `(4,3)`，弦长为 8。也可以从图形看：圆心到直线的距离为 3，半径为 5，半弦长为 `√(5^2-3^2)=4`。

两种方法相互检查。联立后若出现无实根，对应直线与圆相离；一个重根对应相切；两个不同实根对应相交。

### 专题 5：条件概率先改变样本空间

某批零件中，甲机器生产 60%，次品率 1%；乙机器生产 40%，次品率 3%。随机抽到一个零件，求它是次品的概率。

```text
P(次品)
= P(甲)P(次品|甲) + P(乙)P(次品|乙)
= 0.6*0.01 + 0.4*0.03
= 0.018
```

所以次品概率为 1.8%。不能直接把 1% 与 3% 做算术平均，因为两台机器的产量权重不同。

如果已经知道抽到的是次品，再问“来自乙机器的概率”，样本空间已经改变，需要使用贝叶斯公式：

```text
P(乙|次品) = 0.4*0.03/0.018 = 2/3
```

### 专题 6：导数优化必须检查现实边界

用 100 米围栏靠一面直墙围成长方形，只围其余三边。设垂直墙的边长为 `x` 米，沿墙的边长为 `y` 米。

```text
2x + y = 100
y = 100 - 2x
S(x) = x(100-2x) = 100x-2x^2
定义域：0 < x < 50
```

求导：

```text
S'(x) = 100 - 4x
S'(x)=0 得 x=25
y=50
```

`x<25` 时导数为正，`x>25` 时导数为负，所以面积先增后减，最大面积为 `25*50=1250 平方米`。只写 `S'(x)=0` 还不完整，必须检查定义域以及驻点是否真是最大值。

### 常见易错点

| 易错做法 | 正确诊断 |
| --- | --- |
| 忽略函数定义域就化简或求值 | 定义域是函数的一部分，约去因式也不能删除原限制 |
| `log_a(x+y)=log_a x+log_a y` | 对数把乘法化为加法，不把加法拆开 |
| 用正弦定理解 SSA 时只保留一个角 | 还要检查补角是否也能构成三角形 |
| 归纳法只验证若干个 `n` | 有限个例子不能代替从 `k` 到 `k+1` 的证明 |
| 求出导数为 0 的点就宣布最值 | 还要比较符号、边界和现实约束 |
| 把互斥事件当作独立事件 | 非零概率的互斥事件不可能独立 |
| 相关显著就解释为因果 | 统计关联还需要研究设计与机制支持 |

### 分层练习

**复习巩固。**

1. 求函数 `f(x)=ln(2-x)` 的定义域。
2. 已知等差数列 `a1=4,d=3`，求 `a10` 和 `S10`。
3. 求向量 `a=(1,2)` 与 `b=(2,-1)` 的数量积，并判断夹角。

**综合运用。**

4. 解不等式 `2^x>8`，并说明所用函数性质。
5. 在 `△ABC` 中，`b=3,c=5,A=60°`，求边 `a`。
6. 随机抛两枚均匀骰子，已知点数和为 8，求其中至少有一枚为 5 的概率。

**拓广探索。**

7. 用二分法求 `x^2-2=0` 在 `(1,2)` 内的正根区间，使区间长度不超过 `1/16`。
8. 椭圆 `x^2/9+y^2/4=1` 的焦点在哪里？直线 `x=3` 与椭圆有几个公共点？
9. 一张长方形纸板长 30 厘米、宽 20 厘米，从四角各剪去边长为 `x` 的正方形后折成无盖盒。写出体积函数及定义域，并说明怎样寻找最大体积。

### 练习答案与提示

1. `2-x>0`，所以定义域为 `(-∞,2)`。
2. `a10=31`，`S10=10(4+31)/2=175`。
3. `a·b=2-2=0`，两个非零向量垂直，夹角为 `90°`。
4. `8=2^3`，底数 `2>1`，指数函数递增，所以 `x>3`。
5. 余弦定理：`a^2=3^2+5^2-2*3*5*cos60°=19`，所以 `a=√19`。
6. 条件样本空间为 `(2,6),(3,5),(4,4),(5,3),(6,2)`，其中两种符合，概率 `2/5`。
7. 可得到 `[1.375,1.4375]`，长度为 `1/16`；继续二分可得到更短区间。
8. `c=√(9-4)=√5`，焦点为 `(±√5,0)`；`x=3` 只在 `(3,0)` 相切，有一个公共点。
9. `V(x)=x(30-2x)(20-2x)`，定义域 `0<x<10`。展开后求导，找定义域内驻点，并与接近两端时的体积比较。
