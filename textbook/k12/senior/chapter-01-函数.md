# 第 1 章：函数

> **本章核心：** 函数规定一个对应关系，使定义域内每个输入 `x` 都有唯一输出 `f(x)`。研究函数必须同时看定义域、对应关系和值域。
>
> **最小例题：** `f(x) = 2x + 1`，当 `x = 3` 时，`f(3) = 7`。若没有说明允许哪些 `x`，函数信息就不完整。
>
> **过关标准：** 能判断一个关系是否为函数，求定义域和值域，并在解析式、表格和图像之间转换。

### 1.1 函数的直觉

函数就是一个规则：

```text
输入 x
经过规则 f
输出 y
```

写成：

```text
y = f(x)
```

你可以先把函数想象成一台机器：左边输入，机器按规则处理，右边输出。

![函数机器示意图]({{ '/textbook/assets/functions/function-machine.png' | relative_url }})

例子：

```text
f(x) = 2x + 1
f(3) = 7
```

### 1.2 函数与现实模型

现实中的许多对应关系都可以看作函数：

```text
输出 = 规则(输入)
```

例如：

```text
时间 -> 气温记录 -> 对应时刻的气温
```

计费规则也是函数：

```text
用电量 -> 阶梯电价规则 -> 应付电费
```

所以你学函数，不是为了背符号，而是为了理解“规则如何把输入变成输出”。

### 1.3 自变量和因变量

在：

```text
y = f(x)
```

里面：

- `x` 是自变量，也就是输入。
- `y` 是因变量，也就是输出。
- `f` 是规则。

### 1.4 定义域和值域

定义域：允许输入的范围。

值域：可能输出的范围。

例如：

```text
f(x) = √x
```

在实数范围内，`x` 不能小于 0。

原因是：

```text
负数没有实数范围内的算术平方根。
```
