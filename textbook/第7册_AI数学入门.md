# 第 7 册：AI 数学入门

这一册把前面的数学合起来，用于理解机器学习和深度学习。

你不需要先变成数学专家。你需要知道：

```text
数据如何表示
模型如何计算
误差如何定义
参数如何更新
效果如何评估
```

## 第 1 章：数据矩阵

### 1.1 样本和特征

一条数据叫一个样本。

描述样本的变量叫特征。

例如预测房价：

```text
面积、房龄、楼层、地铁距离
```

就是特征。

### 1.2 数据矩阵

一批数据可以写成矩阵：

```text
X = [[样本1特征1, 样本1特征2],
     [样本2特征1, 样本2特征2],
     [样本3特征1, 样本3特征2]]
```

形状：

```text
样本数 x 特征数
```

### 1.3 标签

标签是你希望模型预测的目标。

```text
y = [价格1, 价格2, 价格3]
```

## 第 2 章：线性回归

### 2.1 模型

线性回归：

```text
y = wx + b
```

多特征时：

```text
y = w1*x1 + w2*x2 + ... + wn*xn + b
```

矩阵写法：

```text
Y = XW + b
```

### 2.2 损失

常用均方误差：

```text
MSE = 平均((预测值 - 真实值)^2)
```

### 2.3 NumPy 手写线性回归

```python
import numpy as np

X = np.array([[1], [2], [3], [4]], dtype=float)
y = np.array([[3], [5], [7], [9]], dtype=float)

w = np.array([[0.0]])
b = 0.0
lr = 0.01

for step in range(1000):
    pred = X @ w + b
    error = pred - y
    loss = np.mean(error ** 2)

    grad_w = (2 / len(X)) * X.T @ error
    grad_b = float((2 / len(X)) * np.sum(error))

    w -= lr * grad_w
    b -= lr * grad_b

print(w, b, loss)
```

## 第 3 章：分类

### 3.1 回归和分类

回归预测连续值：

房价、温度、销量
```

```

## 第 4 章：Sigmoid 和 Softmax

### 4.1 Sigmoid

Sigmoid 把任意实数压到 0 到 1：

```text
sigmoid(x) = 1 / (1 + e^-x)
```

适合二分类概率。

Python：

```python
import math

def sigmoid(x):
    return 1 / (1 + math.exp(-x))

print(sigmoid(-2))
print(sigmoid(0))
print(sigmoid(2))
```

### 4.2 Softmax

Softmax 把多个分数变成一组概率。

```text
每个概率都大于 0，总和等于 1。
```

Python：

```python
import numpy as np

scores = np.array([2.0, 1.0, 0.1])
scores = scores - scores.max()
exp_scores = np.exp(scores)
probs = exp_scores / exp_scores.sum()
print(probs)
```

这里先减去最大值，是为了避免指数运算时数值过大导致溢出。减去同一个常数不会改变 softmax 的最终概率。

## 第 5 章：交叉熵损失

### 5.1 直觉

分类模型希望真实类别概率越高越好。

如果真实类别概率是 `p`：

```text
loss = -log(p)
```

### 5.2 例子

```text
p = 0.9 -> loss 小
p = 0.1 -> loss 大
```

这会强烈惩罚“很自信但错得离谱”的预测。

## 第 6 章：神经网络

### 6.1 一层网络

```text
h = activation(XW + b)
```

其中：

- `XW + b` 是线性变换。
- `activation` 是非线性激活函数。

### 6.2 为什么需要激活函数

如果没有激活函数，多层线性变换叠起来仍然只是线性变换。

激活函数让神经网络能表达复杂关系。

### 6.3 常见激活函数

```text
ReLU(x) = max(0, x)
Sigmoid
Tanh
```

ReLU 最常用：

```python
import numpy as np

def relu(x):
    return np.maximum(0, x)
```

## 第 7 章：反向传播

### 7.1 反向传播解决什么问题

神经网络有很多参数。

我们要知道每个参数对最终损失的影响。

反向传播就是高效计算这些梯度的方法。

### 7.2 数学核心

反向传播的数学核心是：

```text
链式法则
```

从损失开始，一层一层往回计算梯度。

### 7.3 训练循环

```text
前向计算预测
计算损失
反向传播梯度
更新参数
重复
```

## 第 8 章：CNN 和图像

### 8.1 CNN 为什么适合图像

图像有局部结构：

- 边缘。
- 角点。
- 纹理。
- 局部形状。

卷积神经网络用卷积核提取局部特征。

### 8.2 卷积层

传统图像处理中卷积核由人设计。

CNN 中卷积核由数据训练出来。

这句话很重要：

```text
CNN = 可学习的图像滤波器组合。
```

### 8.3 池化

池化用于降低尺寸、增强局部稳定性。

常见最大池化：

```text
取局部区域最大值。
```

## 第 9 章：过拟合和泛化

### 9.1 过拟合

模型把训练数据记得太死，新数据表现不好。

### 9.2 泛化

泛化是模型在没见过的数据上表现好的能力。

### 9.3 常见方法

- 增加数据。
- 数据增强。
- 正则化。
- Dropout。
- 早停。
- 简化模型。

## 第 10 章：模型评估

### 10.1 训练集、验证集、测试集

- 训练集：训练模型。
- 验证集：调参数。
- 测试集：最终评估。

不要用测试集反复调模型，否则测试结果会虚高。

### 10.2 回归指标

```text
MAE：平均绝对误差
MSE：均方误差
RMSE：均方根误差
```

### 10.3 分类指标

```text
Accuracy
Precision
Recall
F1
AUC
```

不同业务关注不同指标。

医学筛查通常更重召回率。

垃圾信息过滤通常要兼顾误杀率。

## 第 11 章：从传统图像处理到深度学习

### 11.1 传统图像处理

传统方法：

```text
人工设计规则
```

例如：

- Sobel 检测边缘。
- 阈值分割。
- 轮廓检测。

### 11.2 深度学习视觉

深度学习方法：

```text
让模型从数据中学习规则
```

例如：

- 图像分类。
- 目标检测。
- 语义分割。
- OCR。

### 11.3 两者不是互相替代

很多工程里会混合使用：

```text
传统图像预处理 + 深度学习识别
```

例如工业缺陷检测：

```text
光照校正 -> ROI 提取 -> 模型分类 -> 规则复核
```
