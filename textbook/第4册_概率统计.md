# 第 4 册：概率统计

概率统计研究不确定性和数据规律。

AI 不是“永远正确”的系统，它输出的是基于数据的可能性判断。所以学 AI 必须懂概率统计。

## 第 1 章：随机事件

### 1.1 事件

事件就是可能发生的事情。

例如：

- 掷骰子得到 6。
- 明天下雨。
- 图片中有猫。

### 1.2 概率

概率表示事件发生的可能性：

```text
0 <= P(A) <= 1
```

如果 `P(A) = 0`，表示不可能发生。

如果 `P(A) = 1`，表示一定发生。

## 第 2 章：条件概率和贝叶斯

### 2.1 条件概率

条件概率：

```text
P(A | B)
```

表示在 `B` 已经发生的条件下，`A` 发生的概率。

### 2.2 贝叶斯公式

```text
P(A | B) = P(B | A) P(A) / P(B)
```

这里要求 `P(B) > 0`，否则条件概率没有意义。

直觉：看到新证据 `B` 后，更新对 `A` 的判断。

### 2.3 AI 中的用途

- 垃圾邮件分类。
- 医学检测。
- 风控。
- 朴素贝叶斯分类器。

## 第 3 章：随机变量

### 3.1 随机变量是什么

随机变量是把随机结果变成数字。

例如掷骰子：

```text
X = 点数
```

那么 `X` 可能是：

```text
1, 2, 3, 4, 5, 6
```

### 3.2 离散和连续

离散随机变量：取值一个一个数得清。

连续随机变量：可以取一个范围内任意值。

例如：

- 骰子点数：离散。
- 身高体重：连续。

## 第 4 章：常见分布

### 4.1 伯努利分布

只有两种结果：

```text
成功 / 失败
1 / 0
```

比如点击广告或不点击。

### 4.2 二项分布

多次伯努利试验中成功次数的分布。

例如 10 次投篮进了几次。

### 4.3 正态分布

正态分布形状像钟：

```text
中间多，两边少。
```

很多自然和测量误差可以近似看成正态分布。

### 4.4 均匀分布

每个结果机会一样。

例如在 `[0, 1]` 上随机取数。

## 第 5 章：期望和方差

### 5.1 期望

期望可以理解为长期平均值。

离散情形：

```text
E[X] = Σ x * P(x)
```

### 5.2 方差

方差描述数据波动大小：

```text
Var(X) = E[(X - E[X])^2]
```

方差大，说明数据分散。

方差小，说明数据集中。

### 5.3 Python

```python
import numpy as np

data = np.array([1, 2, 3, 4, 5])
print(data.mean())
print(data.var())
```

## 第 6 章：采样和估计

### 6.1 总体和样本

总体：你关心的全部对象。

样本：从总体中抽出来的一部分。

统计学经常用样本估计总体。

### 6.2 样本均值

```text
样本均值 = 所有样本值之和 / 样本数量
```

### 6.3 抽样误差

样本不可能完美代表总体，所以会有误差。

样本越大，通常估计越稳定。

## 第 7 章：最大似然

### 7.1 似然是什么

似然问的是：

```text
什么参数最可能产生我们看到的数据？
```

### 7.2 最大似然估计

最大似然估计就是找一组参数，使观测数据出现的可能性最大。

机器学习中，很多训练目标都可以看作最大似然。

## 第 8 章：假设检验

### 8.1 基本思想

假设检验用于判断一个现象是不是可能只是随机波动。

例如：

```text
新按钮点击率比旧按钮高，是真的有效，还是碰巧？
```

### 8.2 p 值直觉

p 值越小，说明在原假设成立时，观察到当前结果越不寻常。

注意：p 值不是“假设为真的概率”。

## 第 9 章：相关和回归

### 9.1 相关

相关描述两个变量一起变化的程度。

- 正相关：一个变大，另一个也倾向变大。
- 负相关：一个变大，另一个倾向变小。
- 不相关：没有明显线性关系。

### 9.2 相关不等于因果

两个变量相关，不代表一个导致另一个。

这是数据分析里最容易犯的错误之一。

### 9.3 线性回归

线性回归用一条直线拟合数据：

```text
y = wx + b
```

目标是让预测误差尽量小。

## 第 10 章：分类评估指标

### 10.1 混淆矩阵

二分类中有四种情况：

```text
TP：实际为正，预测为正
FP：实际为负，预测为正
TN：实际为负，预测为负
FN：实际为正，预测为负
```

### 10.2 准确率

```text
Accuracy = (TP + TN) / 全部样本
```

### 10.3 精确率和召回率

```text
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
```

图像检测、医学筛查、风控中很常见。

## 第 11 章：交叉熵

### 11.1 二分类交叉熵直觉

如果真实标签是 1，模型给出的概率 `p` 越接近 1 越好。

损失：

```text
-log(p)
```

如果 `p = 0.9`，损失小。

如果 `p = 0.1`，损失大。

Python：

```python
import math

for p in [0.9, 0.5, 0.1]:
    print(p, -math.log(p))
```

## 第 12 章：本册综合练习

1. 概率的取值范围是什么？
2. `P(A | B)` 表示什么？
3. 方差大说明什么？
4. 相关是否等于因果？
5. 分类中 Recall 的公式是什么？

答案：

```text
1. 0 到 1。
2. 在 B 发生条件下 A 发生的概率。
3. 数据波动大、分散。
4. 不等于。
5. Recall = TP / (TP + FN)。
```

## 第 13 章：本册小结

你需要记住：

- 概率描述不确定性。
- 贝叶斯公式用于根据证据更新判断。
- 期望是长期平均，方差是波动大小。
- 最大似然是很多机器学习训练目标的基础。
- 准确率、精确率、召回率用于评估分类模型。
- 交叉熵是分类模型中最常见的损失函数之一。
