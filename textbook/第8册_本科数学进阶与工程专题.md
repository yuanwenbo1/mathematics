# 第 8 册：本科数学进阶与工程专题

这一册覆盖本科阶段常见的进阶数学专题，并说明它们如何连接工程、科学、计算、金融、信息、管理等不同应用场景。

它不是要求你一次学完全部，而是作为本科知识地图：当你进入某个方向时，知道应该补哪一块。

## 第 1 章：高级线性代数

### 1.1 向量空间

向量空间是一组可以相加、可以数乘的对象。

常见例子：

- 二维向量。
- 三维向量。
- 多维特征向量。
- 函数空间。

AI 中的嵌入向量、图像特征、模型参数都可以放在向量空间里理解。

### 1.2 基和维度

基是一组最基本的方向。

维度是需要多少个独立方向才能表示空间中的元素。

例如二维平面需要两个基向量：

```text
[1, 0], [0, 1]
```

### 1.3 特征分解

对某些矩阵：

```text
A = PDP^-1
```

可以用特征值和特征向量分解。

注意：不是所有矩阵都能这样分解。这里说的是可对角化矩阵。入门阶段先知道“有些矩阵可以用特征方向拆开理解”即可。

用途：

- PCA。
- 稳定性分析。
- 图算法。
- 马尔可夫链。

### 1.4 正定矩阵

正定矩阵常出现在优化和统计中。

直觉：

```text
它对应的二次型像一个向上的碗，适合寻找最小值。
```

## 第 2 章：多元微积分

### 2.1 多元函数

```text
f(x, y, z)
```

多个输入共同决定输出。

机器学习损失函数通常依赖成千上万个参数。

### 2.2 梯度、雅可比、海森矩阵

梯度：

```text
一阶偏导数组成的向量。
```

雅可比矩阵：

```text
多个输出对多个输入的一阶偏导数组成的矩阵。
```

海森矩阵：

```text
二阶偏导数组成的矩阵。
```

用途：

- 优化。
- 牛顿法。
- 反向传播。
- 机器人运动学。

### 2.3 多重积分

多重积分用于计算区域或空间上的累积量。

图像处理中，可以把区域内所有像素求和看成离散积分。

## 第 3 章：微分方程

### 3.1 微分方程是什么

含有未知函数及其导数的方程。

```text
dy/dt = ky
```

描述“变化率和当前状态有关”的系统。

### 3.2 常微分方程 ODE

常微分方程只有一个自变量，常见是时间。

用途：

- 物理仿真。
- 控制系统。
- 机器人运动。
- 神经 ODE。

### 3.3 偏微分方程 PDE

偏微分方程有多个自变量。

用途：

- 热传导。
- 流体。
- 图像去噪。
- 图像扩散模型中的连续过程理解。

## 第 4 章：数值分析

### 4.1 为什么需要数值方法

很多数学问题没有简单解析解，只能近似计算。

数值分析研究：

- 误差。
- 稳定性。
- 迭代算法。
- 近似求解。

### 4.2 浮点误差

计算机中的小数不是无限精确的。

```python
print(0.1 + 0.2)
```

输出不一定正好是 `0.3`。

### 4.3 数值求导和数值积分

数值求导：

```text
f'(x) ≈ (f(x+h) - f(x)) / h
```

数值积分：

```text
把面积切成很多小块相加。
```

## 第 5 章：最优化

### 5.1 无约束优化

目标：

```text
min f(x)
```

常见方法：

- 梯度下降。
- 牛顿法。
- 拟牛顿法。

### 5.2 约束优化

目标带限制：

```text
min f(x)
subject to g(x) <= 0
```

用途：

- 资源分配。
- 投资组合。
- 路径规划。
- 模型压缩。

### 5.3 凸优化

凸优化研究形状良好的优化问题。

直觉：

```text
如果地形像一个碗，那么局部最低点就是全局最低点。
```

## 第 6 章：信息论

### 6.1 信息量

越不容易发生的事情，发生后提供的信息越多。

信息量：

```text
I(x) = -log P(x)
```

### 6.2 熵

熵衡量不确定性。

```text
H = -Σ p log p
```

用途：

- 决策树。
- 压缩。
- 交叉熵损失。
- 语言模型。

### 6.3 KL 散度

KL 散度衡量两个概率分布的差异。

在深度学习、变分推断、模型蒸馏中常见。

注意：KL 散度不是普通距离，因为通常：

```text
KL(P || Q) 不等于 KL(Q || P)
```

## 第 7 章：随机过程

### 7.1 随机过程是什么

随机过程是一串随时间变化的随机变量。

例如：

- 股票价格。
- 用户访问序列。
- 传感器噪声。
- 视频帧变化。

### 7.2 马尔可夫链

马尔可夫链的核心假设：

```text
下一步只依赖当前状态。
```

用途：

- PageRank。
- 排队系统。
- 强化学习。
- 文本生成早期模型。

## 第 8 章：图论进阶

### 8.1 最短路

常见算法：

- Dijkstra。
- Bellman-Ford。
- Floyd。

用途：

- 地图导航。
- 网络路由。
- 知识图谱推理。

### 8.2 最小生成树

在连接所有节点的前提下，让总边权最小。

用途：

- 网络布线。
- 聚类。
- 图像分割中的图方法。

### 8.3 网络流

研究网络中最大能通过多少流量。

用途：

- 匹配。
- 任务分配。
- 供应链。
- 图像分割。

## 第 9 章：抽象代数入门

### 9.1 为什么需要

抽象代数在普通 AI 入门中不是主线，但在密码学、编码理论、对称性、计算机科学理论中很重要。

### 9.2 群

群是一种带运算的集合，满足封闭、结合、单位元、逆元。

用途：

- 对称性。
- 加密。
- 纠错码。
- 机器人姿态。

## 第 10 章：复数和复变函数

### 10.1 复数

复数：

```text
z = a + bi
```

其中：

```text
i^2 = -1
```

### 10.2 为什么重要

复数在信号处理和傅里叶变换中非常重要。

图像频域处理也绕不开复数。

### 10.3 欧拉公式

```text
e^(iθ) = cosθ + i sinθ
```

它把指数、三角函数和复数连在一起。

## 第 11 章：测度与高级概率直觉

### 11.1 为什么不是入门主线

严格概率论需要测度论作为基础，但多数工程学习不需要一开始深入。

你只需要先知道：

```text
概率是对集合大小的一种抽象度量。
```

### 11.2 什么时候需要

当你学习：

- 深入概率论。
- 随机过程。
- 统计学习理论。
- 生成模型理论。

才需要补测度论。

## 第 12 章：计算几何

### 12.1 常见问题

- 点是否在多边形内。
- 两条线段是否相交。
- 凸包。
- 最近点。
- 多边形面积。

### 12.2 图像和视觉中的用途

- 目标框。
- 轮廓。
- OCR 文本框。
- 相机投影。
- 三维重建。

## 第 13 章：工程数学分流表

| 方向 | 优先补哪些本科数学 |
|---|---|
| 图像处理 | 线性代数、多元微积分、傅里叶、数值分析、计算几何 |
| 深度学习 | 线性代数、概率统计、优化、信息论 |
| 算法工程 | 离散数学、图论、复杂度、组合数学 |
| 量化交易 | 概率统计、随机过程、优化、时间序列 |
| 机器人 | 线性代数、多元微积分、微分方程、优化 |
| 密码学 | 数论、抽象代数、离散数学 |
| 计算机图形学 | 线性代数、几何、微积分、数值方法 |

## 第 14 章：本册小结

本科数学不是一座山，而是一张地图。

主线是：

```text
线性代数
微积分
概率统计
离散数学
优化
数值计算
```

拓展方向是：

```text
微分方程
傅里叶和复数
信息论
随机过程
图论进阶
抽象代数
计算几何
测度论
```

你不需要一次学完所有拓展内容。先根据目标选择分支。
