# 第 5 册：离散数学与算法数学

连续数学研究曲线和变化，离散数学研究一个一个分开的对象。

软件开发和算法大量处理离散对象：

- 数组元素。
- 字符串字符。
- 图中的节点。
- 树上的分支。
- 程序中的条件逻辑。

## 第 1 章：集合

### 1.1 集合是什么

集合是一堆对象组成的整体。

```text
A = {1, 2, 3}
B = {3, 4, 5}
```

### 1.2 常见操作

并集：

```text
A ∪ B = {1, 2, 3, 4, 5}
```

交集：

```text
A ∩ B = {3}
```

差集：

```text
A - B = {1, 2}
```

Python：

```python
A = {1, 2, 3}
B = {3, 4, 5}
print(A | B)
print(A & B)
print(A - B)
```

## 第 2 章：逻辑

### 2.1 命题

命题是能判断真假的陈述。

例如：

```text
3 > 2
今天下雨
```

### 2.2 与、或、非

```text
A and B：A 和 B 都真才真
A or B：A 或 B 至少一个真就真
not A：A 的反面
```

编程里条件判断本质就是逻辑。

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("允许进入")
```

## 第 3 章：排列组合

### 3.1 加法原理和乘法原理

加法原理：几类选择互斥，总数相加。

乘法原理：几步选择连续发生，总数相乘。

### 3.2 排列

排列考虑顺序。

从 5 个人中选 2 个排队：

```text
5 * 4 = 20
```

### 3.3 组合

组合不考虑顺序。

从 5 个人中选 2 个：

```text
C(5, 2) = 10
```

组合公式：

```text
C(n, k) = n! / (k!(n-k)!)
```

这里要求 `n` 和 `k` 是非负整数，并且 `0 <= k <= n`。

Python：

```python
import math

print(math.comb(5, 2))
```

## 第 4 章：递归

### 4.1 递归是什么

递归就是函数调用自己。

递归需要两个部分：

- 终止条件。
- 递推关系。

### 4.2 阶乘

```text
n! = n * (n-1)!
0! = 1
```

Python：

```python
def fact(n):
    if n == 0:
        return 1
    return n * fact(n - 1)

print(fact(5))
```

### 4.3 递归和树

很多算法天然递归：

- 树遍历。
- DFS。
- 分治。
- 动态规划。

## 第 5 章：数学归纳法

### 5.1 直觉

数学归纳法像推倒一排牌：

1. 证明第一个成立。
2. 证明如果第 `k` 个成立，那么第 `k+1` 个也成立。

于是全部成立。

### 5.2 算法中的意义

递归算法正确性经常用归纳法理解。

例如：

- 归并排序为什么正确。
- 动态规划状态转移为什么正确。

## 第 6 章：图论

### 6.1 图是什么

图由节点和边组成。

```text
G = (V, E)
```

- `V` 是节点集合。
- `E` 是边集合。

例子：

- 地图导航。
- 社交网络。
- 任务依赖。
- 神经网络结构。

### 6.2 有向图和无向图

无向图：边没有方向。

有向图：边有方向。

### 6.3 权重

边可以有权重：

```text
距离、时间、成本、相似度
```

## 第 7 章：树

### 7.1 树是什么

树是一种没有环的连通图。

常见概念：

- 根节点。
- 父节点。
- 子节点。
- 叶子节点。
- 深度。

### 7.2 树的用途

- 文件目录。
- DOM 结构。
- 决策树。
- 二叉搜索树。
- 语法解析。

## 第 8 章：搜索算法

### 8.1 BFS

BFS 是广度优先搜索。

特点：一层一层往外搜。

适合求无权图最短路径。

### 8.2 DFS

DFS 是深度优先搜索。

特点：先一路走到底，再回退。

适合遍历、连通性、回溯。

## 第 9 章：复杂度 Big-O

### 9.1 为什么需要复杂度

复杂度描述算法随着输入规模变大，耗时或内存如何增长。

### 9.2 常见复杂度

```text
O(1)       常数时间
O(log n)   对数时间
O(n)       线性时间
O(n log n) 常见高效排序
O(n^2)     双重循环
O(2^n)     指数级，很危险
```

### 9.3 例子

遍历数组：

```python
for x in xs:
    print(x)
```

复杂度：

```text
O(n)
```

双重循环：

```python
for i in range(n):
    for j in range(n):
        pass
```

复杂度：

```text
O(n^2)
```

## 第 10 章：动态规划

### 10.1 动态规划的直觉

动态规划解决的是：

```text
大问题可以拆成小问题，小问题会重复出现。
```

核心：

- 定义状态。
- 写出转移。
- 设置初始条件。

### 10.2 斐波那契

```text
f(n) = f(n-1) + f(n-2)
```

普通递归会重复计算。

动态规划会把结果存下来。

Python：

```python
def fib(n):
    if n == 0:
        return 0
    dp = [0] * (n + 1)
    dp[0] = 0
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

print(fib(10))
```

## 第 11 章：贪心算法

### 11.1 贪心是什么

贪心算法每一步都选当前看起来最好的选择。

不是所有问题都适合贪心。

适合贪心的问题需要满足某种“局部最优能推出全局最优”的结构。

### 11.2 例子

区间调度：

```text
每次选择结束最早的活动。
```

这个策略可以得到最多不冲突活动数。
