# 第 3 册：微积分与优化

微积分研究变化。优化研究怎么让结果更好。

AI 模型训练的核心就是：

```text
计算误差如何变化，然后沿着让误差变小的方向更新参数。
```

这就是导数、梯度和梯度下降的用武之地。

## 第 1 章：变化率

### 1.1 平均变化率

如果 `x` 从 1 变到 3，`y` 从 2 变到 10：

```text
平均变化率 = (10 - 2) / (3 - 1) = 4
```

含义：`x` 每增加 1，`y` 平均增加 4。

### 1.2 瞬时变化率

平均变化率看一段区间。瞬时变化率看某一点附近。

导数就是瞬时变化率。

## 第 2 章：导数

### 2.1 导数的直觉

导数描述函数在某一点变化得多快。

```text
f'(x)
```

表示 `f(x)` 在 `x` 处的变化率。

### 2.2 常见导数

```text
f(x) = x       -> f'(x) = 1
f(x) = x^2     -> f'(x) = 2x
f(x) = x^3     -> f'(x) = 3x^2
f(x) = c       -> f'(x) = 0
f(x) = e^x     -> f'(x) = e^x
f(x) = log(x)  -> f'(x) = 1/x
```

其中 `log(x)` 的导数公式默认 `x > 0`。

### 2.3 导数和斜率

在函数图像上，导数就是切线斜率。

如果导数大于 0，函数在增大。

如果导数小于 0，函数在减小。

如果导数等于 0，可能到了极值点。

## 第 3 章：偏导数和梯度

### 3.1 多变量函数

很多函数不只一个输入：

```text
f(x, y) = x^2 + y^2
```

### 3.2 偏导数

偏导数就是只看一个变量变化，其他变量暂时不动。

```text
∂f/∂x = 2x
∂f/∂y = 2y
```

### 3.3 梯度

梯度把所有偏导数组成一个向量：

```text
∇f = [∂f/∂x, ∂f/∂y]
```

对于：

```text
f(x, y) = x^2 + y^2
```

梯度：

```text
∇f = [2x, 2y]
```

梯度指向函数增长最快的方向。

## 第 4 章：链式法则

### 4.1 为什么需要链式法则

复杂函数经常是一层套一层：

```text
y = (3x + 1)^2
```

可以看成：

```text
u = 3x + 1
y = u^2
```

链式法则用于求这种复合函数的导数。

### 4.2 AI 中的链式法则

神经网络就是很多层函数套在一起。

反向传播本质就是链式法则的系统应用。

```text
输入 -> 第1层 -> 第2层 -> 输出 -> 损失
```

要知道某个参数如何影响最终损失，就要一路往回传导导数。

## 第 5 章：损失函数

### 5.1 什么是损失

损失函数衡量模型预测有多差。

回归常用平方误差：

```text
loss = (预测值 - 真实值)^2
```

分类常用交叉熵。

### 5.2 为什么要最小化损失

训练模型就是寻找参数，使损失尽量小。

```text
最优参数 = 让 loss 最小的参数
```

## 第 6 章：梯度下降

### 6.1 核心思想

梯度指向上升最快方向。

要让函数变小，就往梯度相反方向走：

```text
新参数 = 旧参数 - 学习率 * 梯度
```

### 6.2 学习率

学习率控制每次走多远。

- 太大：可能跳过最低点。
- 太小：收敛很慢。

### 6.3 Python 手写梯度下降

最小化：

```text
f(x) = x^2
```

代码：

```python
x = 10.0
lr = 0.1

for i in range(30):
    grad = 2 * x
    x = x - lr * grad
    print(i, x, x ** 2)
```

你会看到 `x` 逐渐接近 0。

## 第 7 章：泰勒展开

### 7.1 直觉

泰勒展开用简单多项式近似复杂函数。

在某一点附近：

```text
f(x) ≈ f(a) + f'(a)(x - a)
```

这就是一阶近似。

注意：泰勒展开通常是“在某一点附近”的局部近似。离展开点越远，误差可能越大。

### 7.2 为什么重要

优化算法、数值计算、误差分析都依赖“局部近似”。

直觉：在很小范围内，弯曲的函数可以近似看成直线。

## 第 8 章：正则化

### 8.1 过拟合

模型在训练集表现很好，但新数据表现很差，叫过拟合。

### 8.2 正则化

正则化是在损失中加入惩罚项。

常见 L2 正则：

```text
loss = 原始误差 + λ * 参数平方和
```

直觉：不要让参数变得太大，让模型更稳。

## 第 9 章：本册综合练习

1. `f(x) = x^2` 的导数是什么？
2. `f(x) = 3x + 2` 的导数是什么？
3. `f(x, y) = x^2 + y^2` 的梯度是什么？
4. 梯度下降为什么要减去梯度？
5. 学习率太大会发生什么？

答案：

```text
1. 2x
2. 3
3. [2x, 2y]
4. 梯度是上升最快方向，减去梯度就是往下降方向走。
5. 可能震荡甚至发散。
```

## 第 10 章：本册小结

你需要记住：

- 导数是变化率。
- 偏导数是多变量函数对某个变量的变化率。
- 梯度是偏导数组成的向量。
- 梯度下降是 AI 训练的核心算法之一。
- 链式法则是反向传播的数学基础。
- 正则化用来减少过拟合。
