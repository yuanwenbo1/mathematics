# 第 2 册：向量、矩阵与线性代数

线性代数是 AI、图像处理、推荐系统、计算机图形学的底层语言。

你可以先把它理解成一句话：

```text
向量表示一组数，矩阵表示一组规则。
```

图像是矩阵，神经网络参数是矩阵，几何变换也是矩阵。

## 第 1 章：向量

### 1.1 向量是什么

向量是一组有顺序的数。

```text
v = [3, 4]
```

它可以表示：

- 二维平面中的一个方向。
- 一个样本的多个特征。
- 一张图片的一行像素。
- 一个词的语义编码。

例如一个用户：

```text
[年龄, 收入, 消费次数] = [45, 8000, 12]
```

这就是一个特征向量。

### 1.2 向量加法

```text
[1, 2] + [3, 4] = [4, 6]
```

Python：

```python
import numpy as np

a = np.array([1, 2])
b = np.array([3, 4])
print(a + b)
```

### 1.3 向量长度

二维向量 `[x, y]` 的长度：

```text
||v|| = √(x^2 + y^2)
```

例子：

```text
v = [3, 4]
||v|| = 5
```

Python：

```python
import numpy as np

v = np.array([3, 4])
print(np.linalg.norm(v))
```

## 第 2 章：点积

### 2.1 点积是什么

两个向量：

```text
a = [a1, a2]
b = [b1, b2]
```

点积：

```text
a · b = a1*b1 + a2*b2
```

例子：

```text
[1, 2] · [3, 4] = 1*3 + 2*4 = 11
```

Python：

```python
import numpy as np

a = np.array([1, 2])
b = np.array([3, 4])
print(np.dot(a, b))
```

### 2.2 点积的直觉

点积可以衡量两个向量方向是否相似。

```text
点积大：方向接近
点积为 0：大致垂直
点积为负：方向相反
```

推荐系统、文本相似度、图像特征匹配都经常用这个思想。

### 2.3 余弦相似度

```text
cosθ = (a · b) / (||a|| ||b||)
```

余弦相似度越接近 1，说明方向越接近。

## 第 3 章：矩阵

### 3.1 矩阵是什么

矩阵是按行和列排列的数。

```text
A = [[1, 2],
     [3, 4]]
```

它可以表示：

- 一张灰度图。
- 一批数据。
- 一个线性变换。
- 神经网络的一层权重。

### 3.2 图像是矩阵

灰度图可以看成一个矩阵：

```text
[[  0,  20,  50],
 [100, 150, 200],
 [220, 240, 255]]
```

每个数是一个像素亮度。

### 3.3 矩阵形状

如果矩阵有 `m` 行、`n` 列，称为：

```text
m x n 矩阵
```

Python：

```python
import numpy as np

A = np.array([[1, 2], [3, 4], [5, 6]])
print(A.shape)
```

输出：

```text
(3, 2)
```

## 第 4 章：矩阵乘法

### 4.1 规则

矩阵乘法不是对应位置相乘。

如果：

```text
A 是 m x n
B 是 n x p
```

那么：

```text
AB 是 m x p
```

中间维度必须相同。

还要注意：矩阵乘法通常不能交换顺序。

```text
AB 通常不等于 BA
```

有时甚至 `AB` 能算，但 `BA` 根本不能算，因为形状不匹配。

### 4.2 一个例子

```text
A = [[1, 2]]
B = [[3],
     [4]]

AB = 1*3 + 2*4 = 11
```

Python：

```python
import numpy as np

A = np.array([[1, 2]])
B = np.array([[3], [4]])
print(A @ B)
```

### 4.3 为什么矩阵乘法重要

神经网络中一层常写成：

```text
Y = XW + b
```

其中：

- `X` 是输入数据矩阵。
- `W` 是权重矩阵。
- `b` 是偏置。
- `Y` 是输出。

## 第 5 章：线性变换

### 5.1 变换是什么

变换就是把一个向量变成另一个向量。

例如二维点：

```text
[x, y] -> [x', y']
```

### 5.2 缩放

```text
[[2, 0],
 [0, 2]]
```

这个矩阵会把点放大 2 倍。

### 5.3 旋转

二维旋转矩阵：

```text
[[cosθ, -sinθ],
 [sinθ,  cosθ]]
```

这个公式默认使用列向量和数学坐标系：`x` 向右，`y` 向上，正角度逆时针。图像处理中常见坐标系是左上角为原点，`y` 向下，所以实际代码里要确认库函数的坐标约定。

图像旋转、目标框变换、相机几何都会用。

Python：

```python
import math
import numpy as np

theta = math.pi / 2
R = np.array([[math.cos(theta), -math.sin(theta)],
              [math.sin(theta),  math.cos(theta)]])
v = np.array([1, 0])
print(R @ v)
```

## 第 6 章：逆矩阵、行列式、秩

### 6.1 逆矩阵

如果矩阵 `A` 有逆矩阵，记作：

```text
A^-1
```

并且：

```text
A A^-1 = I
```

`I` 是单位矩阵。

直觉：逆矩阵可以把一个变换反过来。

### 6.2 行列式

二维矩阵：

```text
[[a, b],
 [c, d]]
```

行列式：

```text
ad - bc
```

直觉：行列式描述面积被放大或缩小的比例。

如果行列式是 0，说明变换把空间压扁了，矩阵不可逆。

### 6.3 秩

秩描述矩阵中真正独立的信息有多少。

图像和机器学习中，低秩常意味着数据有压缩空间。

## 第 7 章：特征值和特征向量

### 7.1 定义

如果：

```text
Av = λv
```

那么：

- `v` 是特征向量。
- `λ` 是特征值。

直觉：矩阵作用在某些特殊方向上时，只会拉伸或压缩，不改变方向。

### 7.2 为什么重要

特征值和特征向量出现在：

- PCA 降维。
- 图像压缩。
- 推荐系统。
- 稳定性分析。
- 图算法。

Python：

```python
import numpy as np

A = np.array([[2, 0], [0, 3]])
values, vectors = np.linalg.eig(A)
print(values)
print(vectors)
```

## 第 8 章：投影、正交和最小二乘

### 8.1 正交

两个向量点积为 0，说明它们正交：

```text
a · b = 0
```

二维里可以理解成垂直。

### 8.2 投影

投影是把一个向量“投到”另一个方向上。

直觉：影子就是投影。

线性回归本质上和投影思想有关：找一条线，让误差整体最小。

## 第 9 章：SVD 和 PCA 入门

### 9.1 PCA

PCA 的目标是：

```text
用更少的维度保留尽量多的信息。
```

例如把二维点云压到一条主方向上。

### 9.2 SVD

SVD 可以把矩阵分解成：

```text
A = UΣV^T
```

你先不用深究推导，只要知道：

- 它能找出数据中的主方向。
- 它能用于降维和压缩。
- 图像压缩可以用 SVD。

### 9.3 Python 做 PCA 雏形

```python
import numpy as np

X = np.array([[1, 2], [2, 3], [3, 4], [4, 5]])
X_centered = X - X.mean(axis=0)
U, S, Vt = np.linalg.svd(X_centered)
print(Vt[0])
```
