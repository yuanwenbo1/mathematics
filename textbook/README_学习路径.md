# 数学自学教材使用说明

这套教材网站现在定位为“数学专业自学路线”。

它的目标是：从儿童数学启蒙出发，逐步经过小学、初中、高中、本科数学专业核心课程，最后进入研究生阶段的数学研究方向。

它不是只为高考，也不是只为 AI、算法、图像处理、量化或某一个工程领域服务。工程应用会作为“应用层”穿插讲解，用来帮助理解数学方法为什么重要，但网站主线是数学专业学习。

现在也补充了儿童启蒙路径。第前置册和第 0 册加入了适合小朋友的数感、数位、口算、竖式、时间、人民币、图形、数据记录、从空格到未知数等内容。

`分级训练题集.md` 是配套刷题册。建议每学完一册，就做对应册的 A 档和 B 档；隔一天重做错题；C 档在能独立复述概念后再做。

如果给小朋友学习，建议先走：

```text

```

儿童学习不要急着进入函数、矩阵、微积分。先让数感、单位、图形和简单方程变成直觉。

## 本站怎么学

本网站有两条线：

```text
数学专业主线：启蒙 -> 小学 -> 初中 -> 高中 -> 本科 -> 研究生方向
应用理解层：每种数学方法在工程、科学、计算、管理等场景中的用途
```

学习时以数学专业主线为顺序，不要被某一个应用领域带偏。

应用层的作用是帮助你理解：

```text
这个数学方法解决什么问题？
为什么它值得学？
现实问题变成数学模型时发生了什么？
```

## 每天怎么学

推荐每天 90 分钟：

```text
30 分钟：读教材
30 分钟：手算例题和练习
30 分钟：用 Python 验证
```

如果每天只有 45 分钟：

```text
20 分钟：读教材
15 分钟：做练习
10 分钟：复述本章讲了什么
```

## 训练题怎么刷

每一册都按这个顺序训练：

```text
先做 A 档：确认基本计算和定义
再做 B 档：确认是否真的理解
最后做 C 档：用 Python 或应用题把知识用出来
```

不要一边看答案一边做。实在不会，先在题号旁边写下“卡在哪里”，再翻教材对应小节。

## 不要怎么学

不要一上来追求证明严谨。

不要同时开十门课。

不要只看视频不做题。

不要只背公式不写代码。

不要因为一章没完全懂就停住。数学学习经常是“先过一遍，后面回头突然懂了”。

## 渐进学习规则

学每一章都按这个顺序：

```text
先看直觉
再看数字例子
再看公式
再跑 Python
再做练习
最后复述它有什么用
```

如果某个公式看不懂，先不要背。把里面的符号逐个翻译成中文，再代入一个小数字例子。

## 每册验收标准

### 第前置册验收

你应该能：

- 理解数感、单位、比例、表格和图表。
- 会把分数、小数、百分数互相转换。
- 会计算平均数、增长率、转化率。
- 能把生活问题翻译成简单数学表达。

### 第 0 册验收

你应该能：

- 做基本运算。
- 理解变量、代数式和方程。
- 区分 `√49 = 7` 和 `x^2 = 49` 的解是 `±7`。
- 会用 Python 算简单表达式。

### 第 1 册验收

你应该能：

- 说清函数是输入到输出的规则。
- 画一次函数、二次函数的大概图像。
- 知道反比例函数、绝对值函数、分段函数的基本形状和用途。
- 理解指数、对数、三角函数为什么重要。
- 知道阈值判断和不等式的关系。

### 第 2 册验收

你应该能：

- 理解向量、矩阵、点积。
- 会用 NumPy 做矩阵乘法。
- 知道图像为什么是矩阵。
- 知道旋转、缩放可以用矩阵表示。
- 对 PCA、SVD 有基本直觉。

### 第 3 册验收

你应该能：

- 理解导数是变化率。
- 理解梯度是多个方向的变化率组成的向量。
- 能手写 `f(x)=x^2` 的梯度下降。
- 知道链式法则和反向传播有关。

### 第 4 册验收

你应该能：

- 理解概率、条件概率、贝叶斯。
- 会计算均值、方差。
- 知道准确率、精确率、召回率区别。
- 知道交叉熵为什么惩罚低概率真实类别。

### 第 5 册验收

你应该能：

- 理解集合、逻辑、排列组合。
- 看懂递归。
- 知道 BFS、DFS、树、图是什么。
- 会判断常见 Big-O 复杂度。
- 对动态规划有基本状态转移直觉。

### 第 6 册验收

你应该能：

- 用矩阵理解图片。
- 知道卷积、滤波、边缘检测、阈值分割、形态学的作用。
- 能照着代码做一个硬币计数或简单缺陷检测。
- 理解透视变换和文档矫正的关系。

### 第 7 册验收

你应该能：

- 知道数据矩阵、标签、模型、损失、梯度之间的关系。
- 能用 NumPy 手写一个最小线性回归。
- 理解 sigmoid、softmax、交叉熵。
- 知道 CNN 为什么适合图像。
- 知道训练集、验证集、测试集不能混用。

### 第 8 册验收

你不需要一次掌握所有专题，但应该能：

- 知道高级线代、多元微积分、优化、信息论、随机过程分别服务什么方向。
- 知道这些专题怎样连接工程、科学、计算、金融、信息、管理等不同应用方向。
- 遇到本科进阶名词时，能回到第 8 册查它依赖哪些前置知识。

### 第 9 册验收

你应该能：

- 说清数学专业路线和工程数学路线的区别。
- 知道证明训练为什么重要。
- 知道数学分析、高等代数、实变函数、复变函数、抽象代数、拓扑学、泛函分析分别研究什么。
- 能按自己的目标选择数学专业后续方向，而不是盲目从第一本厚教材硬啃。

## 综合项目建议

学完后可以做这些跨领域项目：

1. 用 NumPy 手写矩阵乘法。
2. 用最小二乘拟合一组实验数据。
3. 用函数和导数分析一个成本最小化问题。
4. 用概率统计分析一次抽样调查。
5. 用图论建模一个交通或供应链网络。
6. 用微分方程模拟一个简单的增长或衰减过程。
7. 用傅里叶思想观察声音或周期信号。
8. 用几何和向量分析一个平面运动问题。

## 最重要的一句话

学习数学不是为了记住所有公式，而是为了建立三种能力：

```text
能看懂关系
能推一点过程
能用代码验证
```

这三件事够用以后，再继续学习数学分析、高等代数、实变函数、抽象代数、拓扑学等数学专业内容，会稳很多；再看任何工程应用，也不容易只停留在套公式。
