# 数学自学教材使用说明

这套教材网站面向所有希望系统自学数学的学生。

它的目标是：先完整学完中国小学、初中和高中数学，再按个人目标进入大学基础、应用专题、数学专业核心课程或研究方向。

它不是只为高考，也不是只为 AI、算法、图像处理、量化或某一个工程领域服务。工程应用会作为“应用层”穿插讲解，用来帮助理解数学方法为什么重要，但网站主线是数学专业学习。

前三册不是为某一个人的“数学重启”准备的补丁，而是按国家课程标准组织的完整中小学课程。学习者可以从头学习，也可以先做上一学段结业验收，再从自己的知识缺口开始。

小学、初中和高中三个主文件现在是学段总览页。实际正文按章存放在对应的 `k12` 子目录中，网站会根据 `_data/k12_chapters.json` 生成分章目录、侧栏和连续的上一章/下一章导航。

如果你只想开始学习，先读 `中国中小学数学课程覆盖索引.md`，再进入与自己学段相符的课程。

如果你要从教材一路连续学到题库和下一学段，使用 `中小学连续学习路线.md`。它规定章节顺序、对应题组、回退条件、过关标准和跨学段门槛。

`教材编写规范_防止防自学机制.md` 是给后续扩写用的规则，保证教材不会变成“默认你都懂”的传统写法。

`教材参考资料与版权说明.md` 记录国家课程标准、官方教材资料和本站的原创边界。它用于核对内容范围与教学结构，不是教材原文的转载页。

`分级训练题集.md` 是训练总入口。日常打基础使用小学、初中、高中三套 200 题题库；每学完一册，再做总入口中的 A 档和 B 档检测，隔一天重做错题，C 档在能独立复述概念后再做。

题海训练建议每天 20 题。当天订正，第 2 天重做错题，第 7 天再次复测；同一题组达到 90% 正确率后再进入下一组。

如果从小学开始，建议依次完成：

```text
小学数学全课程：第 1-18 章
小学数学结业验收：第 18 章
初中数学全课程：第 1-21 章
```

小学学习不要急着进入初中函数或大学数学。先让数感、单位、运算、图形、数据和简单方程变成直觉。

## 本站怎么学

本网站有两条线：

```text
数学专业主线：启蒙 -> 小学 -> 初中 -> 高中 -> 本科 -> 研究生方向
应用理解层：每种数学方法在工程、科学、计算、管理等场景中的用途
```

学习时以数学专业主线为顺序，不要被某一个应用领域带偏。

应用层的作用是帮助你理解：

```text
这个数学方法解决什么问题？
为什么它值得学？
现实问题变成数学模型时发生了什么？
```

## 每天怎么学

中小学阶段先按 `中小学连续学习路线.md` 找到当前单元。每天的阅读与训练必须来自同一个单元，不要今天学分数、明天跳到函数、后天又回到几何。

推荐每天 90 分钟：

```text
30 分钟：读教材
30 分钟：手算例题和练习
30 分钟：用 Python 验证
```

如果每天只有 45 分钟：

```text
20 分钟：读教材
15 分钟：做练习
10 分钟：复述本章讲了什么
```

## 训练题怎么刷

每一册都按这个顺序训练：

```text
先做 A 档：确认基本计算和定义
再做 B 档：确认是否真的理解
最后做 C 档：用 Python 或应用题把知识用出来
```

不要一边看答案一边做。实在不会，先在题号旁边写下“卡在哪里”，再翻教材对应小节。

## 不要怎么学

不要一上来追求证明严谨。

不要同时开十门课。

不要只看视频不做题。

不要只背公式不写代码。

不要因为一章没完全懂就停住。数学学习经常是“先过一遍，后面回头突然懂了”。

## 渐进学习规则

学每一章都按这个顺序：

```text
先看直觉
再看数字例子
再看公式
再跑 Python
再做练习
最后复述它有什么用
```

如果某个公式看不懂，先不要背。把里面的符号逐个翻译成中文，再代入一个小数字例子。

## 每册验收标准

### 小学数学全课程验收

你应该能：

- 正确进行整数、小数和分数四则运算，并用估算检查。
- 解决百分数、比、比例、简易方程和常见数量关系问题。
- 计算常见图形的周长、面积、表面积与体积。
- 收集和解释数据，完成一个小学综合实践项目。

### 初中数学全课程验收

你应该能：

- 运算和化简实数、整式、分式与二次根式。
- 解方程、方程组和不等式组。
- 研究一次、反比例和二次函数。
- 完成全等、相似、四边形和圆的几何证明。
- 分析统计数据和简单随机事件。

### 高中数学全课程验收

你应该能：

- 使用集合与逻辑语言表达和推理。
- 综合研究指数、对数、三角等函数及数列、导数。
- 用向量、复数、空间几何和解析几何解决问题。
- 使用计数、概率、随机变量、回归和独立性检验。
- 独立完成数学建模与探究报告。

### 第 2 册验收

你应该能：

- 理解向量、矩阵、点积。
- 会用 NumPy 做矩阵乘法。
- 知道图像为什么是矩阵。
- 知道旋转、缩放可以用矩阵表示。
- 对 PCA、SVD 有基本直觉。

### 第 3 册验收

你应该能：

- 理解导数是变化率。
- 理解梯度是多个方向的变化率组成的向量。
- 能手写 `f(x)=x^2` 的梯度下降。
- 知道链式法则和反向传播有关。

### 第 4 册验收

你应该能：

- 理解概率、条件概率、贝叶斯。
- 会计算均值、方差。
- 知道准确率、精确率、召回率区别。
- 知道交叉熵为什么惩罚低概率真实类别。

### 第 5 册验收

你应该能：

- 理解集合、逻辑、排列组合。
- 看懂递归。
- 知道 BFS、DFS、树、图是什么。
- 会判断常见 Big-O 复杂度。
- 对动态规划有基本状态转移直觉。

### 第 6 册验收

你应该能：

- 用矩阵理解图片。
- 知道卷积、滤波、边缘检测、阈值分割、形态学的作用。
- 能照着代码做一个硬币计数或简单缺陷检测。
- 理解透视变换和文档矫正的关系。

### 第 7 册验收

你应该能：

- 知道数据矩阵、标签、模型、损失、梯度之间的关系。
- 能用 NumPy 手写一个最小线性回归。
- 理解 sigmoid、softmax、交叉熵。
- 知道 CNN 为什么适合图像。
- 知道训练集、验证集、测试集不能混用。

### 第 8 册验收

你不需要一次掌握所有专题，但应该能：

- 知道高级线代、多元微积分、优化、信息论、随机过程分别服务什么方向。
- 知道这些专题怎样连接工程、科学、计算、金融、信息、管理等不同应用方向。
- 遇到本科进阶名词时，能回到第 8 册查它依赖哪些前置知识。

### 第 9 册验收

你应该能：

- 说清数学专业路线和工程数学路线的区别。
- 知道证明训练为什么重要。
- 知道数学分析、高等代数、实变函数、复变函数、抽象代数、拓扑学、泛函分析分别研究什么。
- 能按自己的目标选择数学专业后续方向，而不是盲目从第一本厚教材硬啃。

## 长期完整学习计划

零基础学习应按实际掌握情况推进，不用追赶统一月份。一个可执行的参考是：

```text
小学数学全课程：16-24 周
初中数学全课程：20-30 周
高中数学全课程：24-36 周
大学共同基础每册：4-8 周
每完成一个学段：预留 1-2 周做结业验收和错题回炉
```

## 综合项目建议

学完后可以做这些跨领域项目：

1. 用 NumPy 手写矩阵乘法。
2. 用最小二乘拟合一组实验数据。
3. 用函数和导数分析一个成本最小化问题。
4. 用概率统计分析一次抽样调查。
5. 用图论建模一个交通或供应链网络。
6. 用微分方程模拟一个简单的增长或衰减过程。
7. 用傅里叶思想观察声音或周期信号。
8. 用几何和向量分析一个平面运动问题。

## 最重要的一句话

学习数学不是为了记住所有公式，而是为了建立三种能力：

```text
能看懂关系
能推一点过程
能用代码验证
```

这三件事够用以后，再继续学习数学分析、高等代数、实变函数、抽象代数、拓扑学等数学专业内容，会稳很多；再看任何工程应用，也不容易只停留在套公式。
