# 中国中小学数学课程覆盖索引

本站中小学课程以教育部发布的[《义务教育数学课程标准（2022年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf)和[《普通高中数学课程标准（2017年版2020年修订）》](https://www.moe.gov.cn/srcsite/A26/s8001/202006/t20200603_462199.html)为内容边界。

“完整覆盖”指国家课程标准规定的数学主题、基本方法和实践活动均在教材中有对应讲解、例题或任务，不代表逐页复制某一出版社教材。不同教材版本的章节顺序可能不同，本站按知识依赖重新组织。

## 使用方法

1. 从自己的实际学段开始，先做上一学段结业验收。
2. 若某项不能独立解释或计算，按本索引回到对应章节。
3. 每学完一个领域，完成至少一个不依赖答案的综合任务。
4. 学完一册后再进入下一学段，避免把知识地图误当成已经掌握的知识。

最后核对标准不是“是否看过”，而是能否独立完成：解释概念、规范计算、推理论证、建立模型、分析数据和反思结论。
