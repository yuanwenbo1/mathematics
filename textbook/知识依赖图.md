# 知识依赖图

这份文件说明本网站为什么按这个顺序学习。

当前网站主线面向所有数学自学者。前三册完整覆盖中国中小学课程，后续再分流到大学共同基础、应用专题和数学专业路线。学习顺序由数学知识本身的依赖关系决定。

## 总路径

```text
小学数学全课程
  -> 数数、数位、十进制
  -> 四则运算、单位、图形、表格
  -> 小学分数、小数、百分数、比例、统计图
  -> 初中代数、方程、不等式、函数、平面几何
  -> 高中集合逻辑、函数、三角、数列、解析几何、立体几何、概率统计
  -> 证明训练
  -> 数学分析
  -> 高等代数
  -> 解析几何
  -> 常微分方程
  -> 概率论与数理统计
  -> 复变函数
  -> 实变函数
  -> 抽象代数
  -> 拓扑学
  -> 泛函分析
  -> 微分几何
  -> 偏微分方程
  -> 研究生方向专题
```

## 为什么这样排

### 0. 先从小学数感开始

如果没有数感、单位感、数量比较和空间直觉，后面的数学会变成空符号。

所以最前面先学：

```text
数数 -> 数位 -> 十进制 -> 加减乘除 -> 单位 -> 图形 -> 表格
```

这个阶段不要急着证明，也不要急着抽象。重点是：

```text
能摆出来
能画出来
能说出来
能写成算式
```

### 1. 小学数学打计算和生活建模基础

小学阶段的核心不是难题，而是稳定的基本工具：

```text
整数
小数
分数
百分数
比例
单位换算
周长面积体积
简单统计图
```

这些内容以后会进入：

```text
概率
函数
几何
测量
数据分析
应用建模
```

### 2. 初中数学进入代数和证明

初中是从算术到数学语言的关键过渡。

核心路径：

```text
空格和未知数 -> 变量 -> 代数式 -> 方程 -> 函数
```

几何路径：

```text
图形观察 -> 角和平行 -> 三角形 -> 全等相似 -> 勾股定理 -> 圆
```

初中几何中的证明，是数学专业证明训练的早期入口。

### 3. 高中数学准备大学数学

高中阶段要补齐进入本科数学的语言：

```text
集合与逻辑
函数性质
三角函数
数列
不等式
解析几何
空间向量
复数
导数初步
排列组合
概率统计
```

其中最重要的桥梁是：

```text
集合逻辑 -> 证明
函数极限直觉 -> 数学分析
向量矩阵直觉 -> 高等代数
概率统计 -> 随机数学
解析几何 -> 几何和计算
```

### 4. 本科数学专业从证明开始

进入本科数学专业后，学习重点会明显改变。

你不再只是问：

```text
怎么算？
```

还要问：

```text
定义是什么？
条件是什么？
为什么成立？
有没有反例？
能不能推广？
```

所以本科数学的前置能力是：

```text
集合
逻辑
命题
量词
证明方法
反例意识
```

### 5. 数学分析和高等代数是本科双主干

数学分析通向：

```text
实变函数
复变函数
泛函分析
微分方程
偏微分方程
概率论理论
```

高等代数通向：

```text
抽象代数
表示论
线性代数进阶
数值线代
编码理论
密码学
代数几何
```

这两门课是数学专业本科最重要的两根柱子。

### 6. 本科进阶课开始分方向

常见分支：

```text
分析方向：数学分析 -> 实变函数 -> 泛函分析 -> PDE / 调和分析
代数方向：高等代数 -> 抽象代数 -> 数论 / 代数几何 / 表示论
几何方向：解析几何 -> 多元微积分 -> 拓扑 -> 微分几何
概率方向：概率论 -> 数理统计 -> 随机过程 -> 随机分析
计算方向：线性代数 -> 数值分析 -> 优化 -> 科学计算
离散方向：集合逻辑 -> 图论 -> 组合数学 -> 理论计算机科学
```

### 7. 研究生阶段进入问题和理论

研究生阶段不是“多学几章”，而是开始围绕方向读理论、读论文、找问题。

典型能力：

```text
读懂定义体系
理解定理条件
知道经典反例
掌握常用工具
能做小推广
能提出问题
```

## 应用层如何插入

应用层不改变主线顺序，但会在每个阶段帮助理解。

例如：

```text
比例 -> 配方、缩放、利率、合格率
函数 -> 传感器输入输出、价格模型、控制响应
矩阵 -> 图形变换、数据表、工程结构计算
微积分 -> 速度、热量、边际变化、优化
概率统计 -> 抽样、质量检测、可靠性、风险
图论 -> 交通、电网、供应链、网络
微分方程 -> 振动、流体、传染病、控制系统
拓扑 -> 连通性、空间形状、机器人构型空间
抽象代数 -> 密码学、编码理论、对称性
```

如果应用例子暂时看不懂，不要停住。应用例子是帮助理解，不是该阶段必须全部掌握的工程课程。

## 卡住时怎么处理

如果某章卡住，不要硬熬。

按这个顺序排查：

1. 是不是前置概念没学？
2. 是不是符号没看懂？
3. 能不能换成具体数字？
4. 能不能画图？
5. 能不能找一个生活或工程应用来理解？
6. 能不能写出定义中的每个条件？
7. 是不是需要补一个证明例子或反例？

学习数学最好的状态不是“永远不卡”，而是知道卡在哪里。
