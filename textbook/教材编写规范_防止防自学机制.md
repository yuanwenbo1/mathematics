# 教材编写规范：防止防自学机制

这套教材的目标不是展示作者懂多少，而是让学习者能自己学下去。

很多教材让人学不下去，不是因为知识本身难，而是因为它们经常有这些问题：

- 概念还没解释，就先给符号。
- 公式还没动机，就先给推导。
- 例子太少，跨度太大。
- 习题和例题难度断层。
- 默认读者记得所有前置知识。
- 不说明这个知识以后用在哪里。
- 证明写得很漂亮，但初学者不知道为什么要证明。

本教材要刻意避开这些问题。

## 总原则

每个知识点都按这个顺序讲：

```text
问题从哪里来
直觉是什么
最小例子是什么
公式怎么写
用代码怎么验证
常见误区是什么
练习题怎么做
以后会用在哪里
```

不允许先抛抽象定义，再让读者自己悟。

## 概念依赖原则

任何新概念出现前，必须确认它依赖的旧概念已经讲过。

例如：

```text
梯度 依赖 导数
导数 依赖 函数和变化率
函数 依赖 变量和坐标
矩阵乘法 依赖 向量和点积
卷积 依赖 矩阵和局部加权求和
CNN 依赖 卷积、矩阵、梯度下降
```

如果必须提前出现一个没讲过的词，要标注：

```text
现在先把它当成一个工具，后面第 X 册会正式解释。
```

## 难度递增原则

每章难度只允许增加一小步。

正确节奏：

```text
数字 -> 变量 -> 代数式 -> 方程 -> 函数
函数 -> 斜率 -> 导数 -> 偏导数 -> 梯度
向量 -> 点积 -> 矩阵 -> 矩阵乘法 -> 线性变换
像素 -> 图像矩阵 -> 卷积 -> 滤波 -> 边缘检测 -> CNN
```

错误节奏：

```text
刚讲函数，马上进入多元链式法则。
刚讲矩阵，马上进入 SVD 完整推导。
刚讲概率，马上进入最大似然和 KL 散度。
刚讲卷积，马上进入 ResNet。
```

## 公式使用原则

公式必须服务理解，不是用来吓人。

每个公式都必须回答：

1. 每个符号是什么意思？
2. 这个公式在算什么？
3. 为什么要这么算？
4. 有没有一个带数字的小例子？
5. 能不能用 Python 跑出来？

例如不能只写：

```text
cosθ = (a · b) / (||a|| ||b||)
```

还必须解释：

```text
这是在衡量两个向量方向是否相似。
结果接近 1，方向接近。
结果接近 0，大致垂直。
结果接近 -1，方向相反。
```

## 证明处理原则

初学阶段不追求证明优雅，先追求理解。

证明分三层：

```text
第一层：直觉解释。
第二层：数字例子。
第三层：形式证明。
```

本教材第一版主要覆盖第一层和第二层。

当某个证明对理解非常关键时，再加入第三层。

## 代码验证原则

数学概念尽量用代码验证。

本教材的主线是数学专业。代码验证不是把路线改成编程课，而是用最小实验帮助学习者看清定义、计算过程、近似误差和应用场景。

代码遵循：

- 先用 Python 标准库。
- 再用 NumPy。
- 图像、信号或数值计算专题再引入 OpenCV、SciPy 等工具。
- 统计、优化或 AI 应用专题最后再引入 PyTorch 等框架。

不一开始堆复杂框架。

## 可视化原则

凡是适合看图理解的内容，应优先加入静态图、动态图或小实验。

尤其是这些主题：

```text
函数图像
斜率
二次函数开口
三角函数和单位圆
向量方向
矩阵变换
导数和切线
梯度下降
概率分布
卷积核滑动
边缘检测
傅里叶频率
```

可视化必须服务理解，而不是装饰。

每张图都要回答至少一个问题：

```text
这个概念长什么样？
某个参数改变时，图像怎么变？
公式里的每个量对应图上的什么？
这个数学规则在工程、科学、计算、金融、信息或数据问题里怎么出现？
```

静态图适合：

```text
结构关系
函数对比
公式含义
坐标示意
```

动态图适合：

```text
参数变化
点的运动
函数变形
迭代过程
卷积核滑动
梯度下降路径
```

插图格式统一放在对应教材目录下的 `assets/` 子目录中，并在 Markdown 中用相对路径引用。

## 练习题原则

练习分三档：

```text
A 档：照着例子做，确认会基本操作。
B 档：换一点数字或场景，确认理解。
C 档：小应用，连接工程、科学、计算、金融、信息或数据场景。
```

每章必须有答案。

早期章节必须给详细答案。

后期章节可以给思路，但不能只写“略”。

## 常见误区原则

每章都尽量列常见误区。

例如：

- `√49 = 7`，不是 `±7`；方程 `x^2 = 49` 的解才是 `±7`。
- 矩阵乘法不是对应元素相乘。
- 相关不等于因果。
- 梯度指向上升最快方向，梯度下降要往反方向走。
- 测试集不能参与调参。

这些地方要主动提醒，不等读者踩坑。

## 螺旋上升原则

重要概念会出现多次，但每次只加一点深度。

例如“卷积”：

```text
第 2 册：矩阵和局部计算。
第 6 册：图像卷积核。
第 7 册：CNN 中可学习卷积核。
```

例如“梯度”：

```text
第 1 册：函数变化。
第 3 册：导数和梯度。
第 7 册：反向传播和参数更新。
```

这样不是重复，而是让知识逐渐长出来。

## 本教材的承诺

这套教材后续扩写时遵守：

```text
不跳步骤。
不藏前提。
不把简单问题讲复杂。
不靠大量术语制造门槛。
不出现没解释过的关键符号。
不把答案写成“显然”“易得”“略”。
```

如果某一章读起来突然吃力，优先认为是教材还需要补桥梁，而不是学习者不聪明。
